# 分割连通块的几何约束：完整图像开发

2026-10-22，当前采用版本仍V2。新代码隔离在`variants/initial-observation-01`，输出`outputs/component-geometry-development-01`。本轮不改分割权重，也未训练新残差或执行完整任务。

## 依据与约定

[固定观察位的14次物理诊断](INITIAL_VISIBILITY_REPORT.md)没有恢复检测，且完整640图像中3条HOME失败先选中Z≈0.1m的桌面误分割。比较以下五种预先保存到开发配置的算法，使用完整640复用验证图像及384已知空场景×3姿态的1,152张图像，不挑选成功子集：

1. V2原解码，概率0.60/最小面积25。
2. 保留原连通块，先排除不满足既有工作区的候选，再按置信度排序。
3. 在连通域分析前，使用RGB-D和相机标定把像素反投影到基座坐标；只保留X=0.245–0.50m、|Y|≤0.25m、Z=0.125–0.16m范围内的网络概率。再按0.60、0.55、0.50三个概率阈值分别解码，其余面积、形状、腐蚀核与深度一致性检查不变。

几何范围来自已有任务工作区/已知桌面和标定，不读取物体真值。每帧验证向量反投影与既有标量`deproject`一致；原最大置信解码与逐连通块重建也逐帧一致。真值仅计算开发定位误差。三个姿态相关，不能把1,152图像当独立场景；所有图像已经用于开发，不能当新验收。
