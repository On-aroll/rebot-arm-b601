# HOME 定时重新观察：开发诊断

运行 `outputs/home-refresh-development-01`；独立脚本不改变正在进行的 `goal-egl-coverage-v2-candidate-02` 控制代码。新正场景14000000–14000029、空场景14100000–14100007，与当前正式试验预留种子、其冻结历史账本和训练/验证数据不交叉。

## 动机与做法

两个观察姿态在已审计58次开发对照的静态任务中增加约5.959仿真秒。相机固定在上方，HOME 本身可能已给出清楚视野，因此单独检验：机器人保持 HOME、张爪，固定等待0.8或1.2秒，再拍间隔0.2秒的两帧；门限仍使用候选02的置信度/覆盖率/配对稳定性/80mm更新距离。等待时间不读取推力或物体状态。

每个正场景做有/无相同环境推力、两个等待时间，空场景做两个等待时间，共136次观察运行，但只有30个不同正场景与8个不同空场景。它们不是136个独立任务，更没有执行抓取放置。真值只在图像推理后计算诊断误差，不选择等待或接受观测。

## 结果

| 场景 | 首帧等待 | 末帧检出 | 配对接受 | 接受样本条件误差均值/最大 |
| --- | ---: | ---: | ---: | ---: |
| 静态 | 0.8s | 30/30 | 30/30 | 0.848 / 3.369mm |
| 静态 | 1.2s | 30/30 | 30/30 | 0.848 / 3.369mm |
| 受扰 | 0.8s | 28/30 | 27/30 | 1.043 / 2.327mm |
| 受扰 | 1.2s | 30/30 | 29/30 | 1.016 / 2.327mm |
| 空场景 | 0.8s | 0/8 | 0/8 | 无 |
| 空场景 | 1.2s | 0/8 | 0/8 | 无 |

所有正场景初始均检出，故这批数据未检验初始漏检恢复。0.8秒受扰：14000010的两帧位置相差11.55mm而拒绝；14000015、14000024未检出，图像时物体正在翻滚、顶面超出当前高度先验。1.2秒时仅14000015仍被拒绝，第一帧未检出，第二帧虽检出但误差7.007mm；不能将它从总体中删除或称30/30可靠。受扰接受样本的新位置相对初始平均变化16.502/19.709mm，说明重新观察确实能反映位移。

误差参考为真实旋转立方体的世界包围盒顶面中心：`center + [0,0,abs(R[2]) @ half_size]`。物体倾斜时，它不是通用抓取姿态真值；这些误差不能直接换算成抓取成功率。

## 复现审计

`home_refresh_audit.py` 对全部136次运行重新执行物理、图像、推理及门限，决策与周期RGB-D逐元素相同，全部动作记录相同。3,400条动作、952对RGB-D、408决策帧、81,600物理步，禁止接触0；关节指令始终HOME。检查模型、源码、76资产、参考账本/当前正式预留、数据及种子身份。结果 `outputs/home-refresh-development-01/audit.json` 通过。

这是用冻结探测代码的确定性重跑，不是独立物理引擎，也不是完整任务验收。

```bash
MUJOCO_GL=egl OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python home_refresh_audit.py --run outputs/home-refresh-development-01
```

## 下一步假设

可在当前正式试验及审计结束后开发“先等1.2秒在HOME重观测；视觉合格则直接重规划，否则进入现有观察姿态”。保留现有模型、门限与最多两次抓取重试，单独测量是否减少静态耗时并保留受扰收益。还必须以新场景做完整任务开发、冻结后至少30场景/块对照，不能据本探测采用新控制器。尚未启用，也没有替换V1。
