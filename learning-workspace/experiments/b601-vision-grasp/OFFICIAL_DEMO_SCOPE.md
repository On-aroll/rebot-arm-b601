# 官方 Demo 与本实验支线的关系

查阅日期：2026-10-21。只阅读资料，没有安装驱动或运行实机程序。

Seeed 当前教程包含 Python SDK + RGB-D + YOLO/OBB 路线，以及 ROS 2 + YOLOE 路线；还列出可选的 GraspNet 6D 抓取。前者提供相机、手眼标定、位姿变换及抓放示例，后者支持用文本类别指定抓取/放置目标。[官方教程](https://wiki.seeedstudio.com/cn/rebot_arm_b601_rs_grasping_demo/)

## 对接价值

官方的相机抽象、内参/手眼标定文件和抓取驱动接口，可以作为未来实机适配的参考。教程说明 `scripts/main.py --dry-run` 仍会初始化并移动机械臂；本支线不使用该程序做仿真验证。[官方运行说明](https://wiki.seeedstudio.com/cn/rebot_arm_b601_rs_grasping_demo/#8-%E8%BF%90%E8%A1%8C%E4%B8%8E%E8%B0%83%E8%AF%95)

## 本支线当前要验证的贡献

本轮固定已有的 1,765 参数视觉网络和 1,443 参数残差策略，比较新视觉信息是否通过真实计划更新减少抓空/重试。主要实验变量是闭环反馈，模型权重保持相同。

- 任务层接受 A/B/C 区域目标。
- 观察质量不足时主动移开机械臂重新观察，并保留拒绝原因。
- 新图像改变剩余抓取/搬运/放置计划，逐项记录图像、残差和实际关节命令。
- 独立固定时序推力检验目标移动后的反应；相同观察路径的消融用于判断反馈作用。
- 视觉与自身夹爪反馈检查任务；真值只做训练监督和独立评分。

这是一项可检验的工程研究假设，尚不能宣称方法新颖或实机可用。当前仅验证固定顶视相机、已知桌面高度、单个红橙立方体；没有覆盖任意物体、杂乱场景、语言理解或移动相机。真实相机误差、标定漂移、关节/夹爪映射和执行时延需要后续独立实验。

原始完整任务结果见 `GOAL_V1_REPORT.md`；当前反馈候选状态见 `ITERATION_STATE.json`，正式结论以对应冻结验收报告为准。
