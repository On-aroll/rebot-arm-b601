# R2 预先规定的训练与评估

- 训练：50000000 至 50001279，4 个进程；验证：51000000 至 51000035，固定 36 个场景，简单/中等/困难各 12，A/B/C 均衡。
- 开发探测：52000000 段；正式测试预留 53000000 段，测试不参与选择模型。
- 小型 SAC 64×64 网络，39 维观测，4 维动作。前 36 维沿用 R1，后 3 维是视觉目标与自身 TCP 相对位置；对象真值、接触、评分、注入偏差均不进入演员。
- 修正上限 XYZ 为 12/12/8 mm，夹爪 6 mm；每步位置最多变化 2 mm、夹爪 1.5 mm。
- 五步张开对准 + 原十八步抓取抬升。技能训练成功需双指物理夹持、升高 8 cm、持续 0.4 秒、无违规接触。
- 约 3600 秒学习循环预算，包含周期验证；前后初始/最终验证及正式测试另计。阶段比例 15%/40%/100%，学习率 3e-4/1e-4/3e-5，25%无偏差复习。
- 阶段抓偏幅度 5/20/35 mm（随机平面方向）；较难阶段增加摩擦、质量、相机、深度噪声和响应变化。没有物体吸附或运行中修改位姿。
- 奖励复用 R1 物理抓持/抬升与动作惩罚，增加 gamma*Phi(next)-Phi(current)，Phi=-4*min(视觉平面误差/35mm,2)，终止 Phi=0。
- 验证选择顺序：简单成功数、总成功数、负违规数、负平均修正量。保留初始权重回退点、阶段/周期/最终检查点及所有失败。
- 正式比较冻结 V3、加对准时间但零修正的程序、上一轮 SAC、新 SAC；完整任务最多三次尝试，以原独立物理评分核查放置。必须报告程序改动和模型各自作用。
- 训练关闭时保存未完成尾段，不计完整回合。公开仓库上传已由用户明确授权。

开发探测后的追加预登记（长训练约10分钟，训练参数和36场宽范围测试不变）：另留54000000–54000029共30个新场景，单独检验27/28/29mm可修正边界；正负各15、每个幅度各10、A/B/C各10，使用原真实感参数范围。各场的幅度索引为 `(i//2+i//6)%3`，符号按i奇偶；不复用开发seed。四种控制器配对比较，选择模型仍只用51000000段验证集。训练结束后才运行这批测试，报告与36场测试分开，不挑较好成绩替代较差成绩。
