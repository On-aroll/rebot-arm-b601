# ACT 仿真续研，2026-10-24

用户本轮明确恢复纯仿真实验，覆盖旧交接的暂停要求。本目录复用并核验冻结 V3，默认入口继续为 V3。

1. 用本机 Windows / MuJoCo 3.16.0 / GLFW 重跑基线；与历史 Linux/EGL 成绩分开。
2. 新增未实测的敏感性范围：夹持力、滑动/扭转/滚动摩擦、接触柔度、控制延迟/限速、相机安装偏移、RGB-D 噪声与缺失。它们改善理想化假设的覆盖，不表示完成实机参数辨识。
3. V3 视觉控制教师生成完整轨迹。包含 A/B/C、初始位置/质量/光照变化、外力脉冲、首次抓偏 65mm 和最多两次重试。保留失败，不把真值、阶段名、接触或评分送进策略。失败前缀不作为正确动作示范，成功恢复段保留。
4. 训练小型 RGB-D 条件 CVAE + Transformer 动作分块模型（ACT 的缩小实现，不声称 LeRobot checkpoint 兼容）。输入图像、自身关节/夹爪反馈与上一命令、区域 one-hot；输出下一段六关节绝对目标和夹爪单指米制行程。5Hz 观测/策略更新，底层 500Hz；未来窗口10步，闭环每次只执行首步。
5. 训练场景 41000000 段；验证 42000000 段；开发 43000000 段。首轮锁定配对测试 44000000--44000029；根据其失败补独立训练数据后，第二轮使用全新 45000000--45000029。每组 A/B/C 各10；每3个场景含一个静态、一个时间外力扰动、一个抓偏恢复挑战。禁止用测试轨迹训练。新模型最终选择只依据验证集；如测试后修改策略，必须新测试并保留旧结果。
6. 比较完整任务/首次成功/恢复/误报/碰撞/耗时，保留逐回合证据。最终评分为撤离后连续1秒区域内、桌面支撑、低速、无手指接触，且视觉确认成功。模型推理必须不依赖物体真值；实机板端成本只报告本机CPU测量及待测项。
