# B601-RS 仿真与动作学习报告（2026-10-24）

结论：**继续采用冻结 V3。动作学习候选未达到完整任务要求，不进入实机执行。** 本轮交付可复现的训练/评估流水线和研究权重；没有实现可替代 V3 的学习式动作控制器。

## 做了什么

- 已恢复私有仓库与 V3 原始字节，108个冻结文件哈希全部匹配；Windows/GLFW 上完成原始物理基线完整抓放及冻结源码复跑。旧 Linux/EGL 历史成绩与本轮成绩分开。
- 在独立 `variants/act-01` 中复用原模型和控制器，增加指垫滑动/扭转/滚动摩擦与接触柔度、20–50N夹持力上限、20–60ms命令延迟、速度响应、相机位置偏移与RGB-D噪声/缺失。参数逐回合落盘；它们是未实测的敏感性范围，不能称已完成真实机械臂参数辨识。没有weld、吸附、运行中物体位姿写入。
- 自动采集108个训练场景（72原始+36恢复起点），保留16个失败；92个成功场景中的正确动作及恢复段贡献15002个训练帧。另有12个验证场景、1857个有效验证帧，保留1个失败。错误抓取前缀不当作正确示范。恢复起点来自开发回合的自身姿态，未把正式测试轨迹加入训练。
- 训练小型单RGB-D ACT风格 CVAE/Transformer，参考指定仓库的观测/后续命令契约、episode划分、闭环评估；这是缩小实现，未运行上游双相机LeRobot ACT，不能把本结果当作其效果结论。

## 冻结的正式对照

每轮30个独立新seed，A/B/C各10；静态、时间外力脉冲、首次抓偏65mm各10。首轮为44000000–44000029；补数据后第二轮为45000000–45000029。每组都用同一场景比较V3与该轮候选，重试最多两次。

| 组别 | 完整任务 | 首次成功 | 重试后成功 | 误报成功 | 非法接触步 |
|---|---:|---:|---:|---:|---:|
| 首轮 V3 | 30/30 | 20/30 | 10/30 | 0 | 0 |
| 首轮 ACT | 0/30 | 0/30 | 0/30 | 0 | 0 |
| 补数据后 V3 | 30/30 | 20/30 | 10/30 | 0 | 0 |
| 补数据后 ACT | 0/30 | 0/30 | 0/30 | 0 | 0 |

两轮物理评分共59000行已经从保存的物体几何、速度、支撑与释放证据重新计算，通过独立审计；训练/验证/测试seed不重叠，配对权重和源快照哈希一致。成绩限于单红橙立方体、固定相机、已知桌面，没有复杂背景/障碍/多物体与实机能力证明。

抓偏挑战按各控制器的首次闭爪触发，实际发生时间和自身位姿不同；停滞而未闭爪时不触发，因此不能将配置中的10个挑战理解为模型完成了10次实际恢复测试，也不能声称两者经历相同的扰动后物理轨迹。静态和固定时间外力场景同样没有ACT完整成功。

首轮ACT为26次抓空、2次超时、2次挑战偏移的IK不可达（外部故障注入失败也计失败）。第二轮ACT为30次超时：相对动作减少跳变，但在等待/起步处停滞。V3平均模拟耗时两轮约39.5秒；ACT分别93.0秒、276.9秒，失败超时计入，没有用推理速度替代任务耗时。

## 训练与模型的实际作用

首轮4000步；补36个恢复场景后做8000步弱KL候选（训练/零潜变量推理不一致，未用于正式对照），再做8000步零潜变量正则候选用于第二轮。各自源快照、最后/最佳权重及训练历史全部保留。额外8000步计时候选加入本次目标开始后的时间、每次执行5个预测目标，在3个开发场景中仍为0/3，未采用，也未计入上述60个正式场景。

第二轮选择step=7600，按固定验证集选择；不是按正式测试挑权重。网络输出未来10步的六关节/夹爪目标，正常运动来自模型；视觉启动门槛、验收、限幅、重开夹爪/回HOME与最多两次重试是显式逻辑。额外像素位置特征由RGB-D计算，不使用物体真值或教师阶段。强正则后的潜变量几乎未被利用，不能凭ACT名称宣称学习到了恢复。低离线误差并未转化为完整任务能力。

三个空场景负对照中，V3和第二轮候选均无运动、无误报；这是视觉门槛作用，不是模型自主学会拒绝空场景的证据。

## 本机与板端成本

主机为Core Ultra 5 230F（10核）、约24GB RAM、RTX 5060 Ti 8GB；使用Python 3.12 / MuJoCo 3.16.0 / PyTorch 2.7.1+cu128。小模型训练的CUDA峰值已分配张量内存约72.4MiB（不含显示/运行库/缓存）；第二轮8000步训练循环约129.1秒。

正式交付研究权重为第二轮候选：498,591参数，2.01MB。独立CPU双线程、200次推理（含预处理）中位2.45ms、P95 2.93ms、P99 3.44ms；进程RSS约408.4MiB，较加载模型前增加17.5MiB。TorchScript与原网络10组输入输出最大差为0。**这些是x86主机实测，板端时延、功耗、温度与内存仍未测量。**
