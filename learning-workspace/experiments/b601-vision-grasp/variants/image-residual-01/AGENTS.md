# B601 视觉抓取实验支线

本目录是独立的纯仿真实验。使用本地 `assets/` 模型快照和独立 `.venv/`，不重启主项目。

- 不连接 ROS、CAN、真实相机、机械臂 SDK；本目录的程序不包含实机执行器。
- 图像标签、目标真值只用于合成监督和评估；视觉推理与控制只能接收 RGB-D、相机标定和自身关节状态。
- 禁止以吸附、weld、绑定物体、修改运行中物体位姿来制造成功。初始化允许随机化物体。
- 保留失败轮次、训练与验证划分、源代码快照和模型哈希。报告实际样本规模及任务限制。
- 20 Hz 动作日志、5 Hz 同步 RGB-D 用于后续模仿学习；不能把仿真夹爪米数直接作为 J7 电机弧度。
- 仿真成绩不证明实机能力；实机对接需要独立标定与接入现有保护执行层。
