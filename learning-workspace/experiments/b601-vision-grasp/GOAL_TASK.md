# 目标驱动抓取放置 V0

最新验证版本为 V1，使用 `goal-policy-v2` 配合 `vision-iteration-03/perception.pt`；最新复现命令及完整验收见 [GOAL_V1_REPORT.md](GOAL_V1_REPORT.md)。以下保留 V0 的配置与历史结果，默认感知模型仍为原模型，以便重放旧实验。

任务：人指定 A/B/C 放置区域，B601 在纯仿真中观察随机位置的红橙色方块，自主完成接近、抓取、搬运、松手、后退与结果检查。抓空时重新观察，最多重试两次。

## 运行

```bash
cd /home/bonvoyage/Desktop/1seeed_Robotics/experiments/b601-vision-grasp

# 使用已训练模型执行一个目标，输出独立回放和数据目录。
./task.sh demo --name my-goal-B --policy-run goal-policy-v1 --goal B --seed 8000100

# 在不同初始位置执行另一目标。
./task.sh demo --name my-goal-C --policy-run goal-policy-v1 --goal C --seed 8000101

# 合成数据训练位置修正策略；名称必须是新目录。
./task.sh train --name my-policy --samples 768

# 两个控制版本各运行相同的 30 个保留场景，附加空场景和抓空恢复对照。
./task.sh evaluate --name my-evaluation --policy-run my-policy --episodes 30
.venv/bin/python task_audit.py --run my-evaluation
```

`--goal` 是结构化目标，当前只接受 A/B/C，不提供任意自然语言理解。相机坐标已知，桌面高度固定 0.1m。三个区域中心分别是 `[0.42,-0.16]`、`[0.42,0]`、`[0.42,0.16]` m，半宽均为 0.06m。彩色区域是无碰撞的显示标记。

## 哪些部分学到了控制

- 感知：复用首阶段 RGB-D 分割网络，参数冻结。
- 动作修正：1,443 参数 MLP，输入视觉估计 XYZ、像素中心、面积、置信度和深度，输出每轴最多 ±8mm 的预抓取位置修正，再用于计算实际抓取 TCP 和 IK。
- 训练方式：仿真监督学习，标签为目标顶面真值与视觉估计的差。真值仅在合成训练和独立评分中使用。没有训练强化学习，也不是 ACT 或完整端到端视觉动作策略。
- 显式控制：目标选择、任务阶段、抓取姿态、IK、关节插值、反馈阈值和重试逻辑。
- 策略训练覆盖初始抓取工作区；超出该区时使用几何估计，不外推修正。最终放置检查使用原始视觉估计。

768 个训练场景中，719 个得到可用的视觉与工作区检查结果。192 个验证场景中，180 个可用；这些条件统计不包含感知漏检/拒绝。模型只按验证误差选择：294/300 epoch。位置残差三维误差均值从 2.036mm 降至 1.630mm，中位数 1.475mm 降至 0.967mm，P95 从 6.275mm 降至 6.071mm。这些是验证集条件定位误差，不代表完整任务成功率或实机精度。

初期 `goal-policy-v0` 保留了训练数据过滤不一致的开发记录；正式对照使用 `goal-policy-v1`。两者不能合并成独立测试证据。

## 执行与判断

1. 在 HOME 观察，检查目标置信度和工作区。
2. 位置修正 → 接近 → 下降 → 闭爪 → 提起。
3. 用夹爪关节实际行程检查是否疑似夹住；不读取目标真值或仿真双指接触作决策。
4. 抓空时张爪、返回 HOME、重新观察；最多三次尝试。
5. 搬运到指定区，下降、松手、后退并回 HOME。
6. 用相机确认目标位于区域中心附近、处于桌面高度，夹爪已打开。
7. 独立评分器再检查连续一秒：物体整体位于区域内、由桌面支撑、线速度小于 0.02m/s，且不接触手指。

最终成功要求视觉判断与独立物理评分均通过。单独记录 `controller_success`、`physical_success`、`false_success`，防止视觉误判被隐藏。视觉检查不能证明所有物体姿态与接触状态；独立物理标准仅用于仿真评分。

## 正式对照与数据

训练 seeds 4100000–4100767，验证 4200000–4200191；正式共同测试 9000000–9000029，A/B/C 各 10 次。代码和模型哈希在测试前冻结。几何基线与学习修正使用相同的视觉、IK、任务阶段、反馈检查和重试规则，唯一干预为位置残差。

额外控制：8 个无目标场景，以及同一个新场景下第一次抓取偏移 65mm、允许 0 或 2 次重试的配对试验。所有漏检与失败都保留，测试不用于选择权重。若之后根据本测试修改代码，应把该批标为开发数据并另开新的保留测试集。

每条 episode 保存 `result.json`、20Hz `trajectory.jsonl`、5Hz 配对 `observations.npz`；选定场景提供 GIF。数据含单独标注的仿真评分真值，训练动作模型前必须显式排除。`task_audit.py` 审计数据划分、哈希、速度、限位、重试次数、残差边界、空场景无运动及图像时间配对。

## 限制

仅单个红橙色立方体、已知桌面与固定相机。随机化位置、尺寸、yaw、颜色、质量、摩擦和光照；没有验证杂乱场景、任意物体、视觉遮挡恢复或真实反馈时延。抓空后的有限重试不能等同通用失败诊断。

所有输出 `hardware_executable=false`。没有实机适配器；模拟夹爪米数、控制力矩和 PD 参数不可写入实机。后续迁移仍需完成 [SIM2REAL.md](SIM2REAL.md) 中的标定与保护执行接口。
