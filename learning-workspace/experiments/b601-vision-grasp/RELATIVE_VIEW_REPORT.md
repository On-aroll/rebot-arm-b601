# 观察位置邻域：42次独立物理诊断

2026-10-22，纯仿真、旧场景开发。**不添加新的固定观察位，不宣称任务成功率提升。** 当前310次正式试验的模型、控制代码、配置和协议保持冻结；本诊断不进入其验收分母。

## 方法与边界

复用`geometry-fallback-known-development-01`已完成并审计的七个非注入案例，包括空桌；固定候选模型和匹配残差。每个案例测试原两观察偏移及各自Y方向±30mm邻居，共7×6=42次。每个位置独立重置，先用真实RGB-D/标定和小策略得到抓取前锚点，再完成1.2秒HOME等待/0.2秒帧对、一次实际关节运动和稳定帧对。若初始无有效目标，直接停止，空桌不运动。

控制不使用物体真值。记录结束后，独立评分以物体中心XY和旋转包围盒最高Z为参考，计算原视觉和现有残差修正误差。相机固定；这里改变机械臂姿态和遮挡，不是移动相机。后续观察位从HOME独立出发，与原控制器依次移动的轨迹不同；即使HOME已通过质量检查，本诊断也强制继续观察。实际控制器会保留HOME合格时的短路径。

## 完整结果

数字表示帧对通过现有质量门槛后的**修正误差/mm**；“拒”包括无检测、质量不足或视觉位移超过80mm。5mm/10mm仅用于描述定位误差档位，不是预先约定的完整任务验收门槛。

20个帧对被接受，其中12个修正误差≤5mm、3个>10mm。不能把帧对当独立场景。16400002只有邻4被接受，原误差7.879mm、修正后7.763mm，未找到通过门槛且≤5mm的位置，也没有执行抓放测试。另一方面，邻2的原误差仅2.109mm、修正3.150mm却未通过质量门槛，说明置信度与准确度并不等价。

11100009的三个被接受位置仍偏14mm左右；现有HOME短路径能避开这些位置并完成已知完整任务，不能因强制探测结果而误称当前控制器已经退步。8200003主要因相对旧锚点位移>80mm被拒，已有完整控制器通过重试重定位恢复，不应为此放宽位移保护。
