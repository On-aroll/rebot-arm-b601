# 抓前重新观察：开发记录

这些是开发与门限验证结果，不能代替完整抓放任务验收。当前已验证版本仍为 `GOAL_V1_REPORT.md` 中的 V1。

## 为什么需要质量检查

最初6个旧场景的观察位试验中，单纯检出方块仍可能有约7mm的位置偏差；其中一例置信度达到0.9758。机械臂遮挡及分割范围不足都可能造成偏差。

当前规则使用原始视觉估计、相机内参/外参和已知0.1m桌面高度：从顶面高度估计立方体边长，再计算预期像素面积。分割面积/预期面积需在0.75–1.4，置信度至少0.8；同一位置间隔0.2秒的两帧位置差需不超过4mm。新位置与原估计的距离不超过80mm。该规则依赖当前任务形状和相机设置，未针对任意物体验证。

两个观察位都由初始视觉估计生成，偏移为 `[-0.08,0,0.15]` 和 `[-0.06,0.06,0.12]` 米。两处均不合格时回HOME重新观察；仍不合格则返回并消耗一次有限重试。选择距离投影覆盖率1最近的合格视图，再调用一次小残差策略。

## 固定物理推力

在机械臂保持HOME时，对12个开发种子6000000–6000011运行全部6种条件，共72次。非零力均从仿真0.5秒开始，沿世界坐标Y方向。

| 力 / 持续时间 | 位移10–40mm | Y位移中位数 | Y位移范围 |
| --- | ---: | ---: | ---: |
| 无力 | 0/12 | 约0 | 绝对值小于0.00000005mm |
| 0.8N / 40ms | 1/12 | 5.000mm | 0.334–41.583mm |
| **0.8N / 60ms** | **5/12** | **13.983mm** | **0.732–58.224mm** |
| 1.0N / 40ms | 4/12 | 14.360mm | 1.252–50.018mm |
| 1.0N / 60ms | 3/12 | 51.637mm | 2.576–147.647mm |
| 1.2N / 40ms | 5/12 | 36.288mm | 2.666–72.229mm |

按测试前写入的规则，先最大化10–40mm比例，再取中位数最接近25mm的候选，最后比较最大位移。选中0.8N/60ms，实际冲量0.048N·s。不为单个测试种子调整力度，也不删除微弱或过强位移。

表中非零力位移取脉冲结束0.3秒后的固定快照；字段名含 `settled`，但该时刻不保证物体已经完全静止。无力条件取1.2秒终态。全部72次的禁止接触步数为0。

独立核对通过：72份结果、1,800行动作日志、504帧配对RGB-D；脉冲冲量、时间配对、冻结源哈希和选择规则一致。原始证据 `outputs/force-development-01`，复现命令：

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python force_calibration.py --name my-force-calibration
```
