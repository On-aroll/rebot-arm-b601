# 决策：将两个 ROS 对话成果打包为独立的 Ubuntu 24.04 安装器

- 类型：engineering-decision
- 状态：accepted
- 日期：2026-10-18
- 用户选择：Ubuntu / Kubuntu 24.04，沿用 ROS 2 Jazzy。

## 输入与范围

用户要求读取 `01a144e1-f673-79c2-9d4c-539ea322ca55`（生成末端书写国庆快乐的ROS程序）和 `01a13e02-997e-7540-9723-8838e8bec1a4`（机械臂仿真），将成果整合为其他 Linux 可一键部署的文件。两者的实现共同位于原 `ReBot_Arm_DigitalTwin_RS` 工程，包括未提交的新文件。

## 决定

使用原生安装，交付 `.run` 自解包文件与等价 `.tar.gz`。每次从允许的源码目录生成干净快照；排除开发环境、ROS 编译产物、密钥及所有运行输出。保留完整当前功能和原控制保护。只适配目标机路径、Node 和部署入口，不重写控制器。

固定 Node 22.23.2 及完整带哈希的 Python 3.12 依赖；官方 ROS 源安装包固定为 1.3.0。新机器在最终路径生成 venv 和 colcon 产物。CSP SDK 保留已审核 6415d431 提交的单提交 Git 仓库，无开发 remotes，原运行时 commit / clean-tree 检查继续生效。

版本目录与 `current` 指针分开；配置、程序、真实会话和恢复记录存于 `shared` 并跨版本保留。更新前检查旧服务已退出，自检通过才切换 current。默认安装后只打开网页，软件检查不连接 CAN。实机使能仍经既有现场确认；不迁移其他机械臂的恢复记录，不把重新安装当成解除恢复锁的办法。

现有 LeRobot / ACT 包单独保留，不能与 ROS 同时控制同一 CAN 接口。正式发布到 GitHub 和离线依赖镜像不在本次范围。
