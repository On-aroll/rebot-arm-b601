# MIT 控制台批次 A 交接

任务启动于 2026-10-08，交接于 2026-10-09。范围：A0–A3 软件保护、界面与离线回归；附 B0 架构草图，B1 仅设计，未接入真实执行器。

## 用户现在怎么用

打开 `http://127.0.0.1:8765/zh/studio/console`。主服务已以 **127.0.0.1** 监听，仅本机访问。带 `?pose=hardware` 的旧书签仍可用；没有只读反馈时不会显示假实机，请选择「MuJoCo 仿真（预测）」进行仿真。

1. 在 XYZ 面板输入 mm 坐标，计算预览，再执行仿真到点。默认示例 200/150/200 仅是仿真例子。
2. 七轴摘要一直保留。点击某轴展开详情；切到另一轴会收起上一轴。浏览器只记显示展开偏好，不记实机解锁。
3. 「保存草稿」写本地软件文件；「审核变更」展示逐字段差异，逐次勾选确认后才批准软件配置。批准不是电机写入，也不是物理验收。
4. 「查看变更记录」显示该轴的草稿、软件批准和 Mock 记录。设备测量、软件批准值、草稿分开显示；未读/未确认不填零。
5. 写字、抓取、暂停/继续/取消和轨迹导出位于「已有仿真任务」。手柄仍只显示输入。
6. 关节映射、备份和网关在高级调试中。旧浏览器显示映射保留，不自动升级为后端批准配置；修改方向/偏移会清除对应人工核对标志。静态姿态一致不代表动态映射已完成。

真实执行按钮仍锁定，因为 MIT 独立执行器、动态映射、反馈监控、TCP、负载和停止/失联策略未现场验收。本轮软件停止也不发 CAN stop，不能代替物理急停。

## 参数如何保护

私有目录 `outputs/private_config/`（被 Git 忽略；目录 0700、文件 0600）：

- `machine_profile.json`：带 schema 和 SHA-256 校验和的完整账本，含设备快照、批准软件配置、草稿与事件，分类存储。
- `history/<revision>-<checksum>.json`：每次事务的不可变完整历史版本。保存先写历史，再写临时文件、校验、原子替换当前文件。
- `pre-recovery-*.json`：明确执行历史恢复时保留的原文件。

没有批准记录时 approved 为空。MIT Kp/Kd/前馈以及 v/a/jerk/转矩/限位等字段均为 null，界面显示未确认，不自动填“安全默认值”。当前历史现场值没有导入或重新查询，因而本轮没有声称已备份电机当前寄存器。

模式字段来自参数读回才算设备状态；MIT 增益为逐帧执行配置，不伪装成电机可持久化寄存器。PP 的 vel_max、CSP 的 limit_spd、位置环 loc_kp 均不证明 MIT 速度/加速度已受控。

每轴核对列出身份未知/不匹配、字段缺失、快照过期、读回失败、模式不一致和夹爪未知等阻断原因。数值形式检查不是机械安全范围验收。Approved 与 Draft 的差异不会自动纠正设备；Mock match/mismatch/timeout 只追加软件事件，失败不替换 Approved，也不自动回滚设备。

服务启动、刷新、重连均 LOCKED / armed OFF / drill ON；不自动连 CAN、不自动写参数、不自动续传 MIT 目标。RuntimeCommand 不保存到配置文件。仿真计划令牌绑定起点、配置哈希、任务版本和 60 秒有效期，执行一次即消费；配置变更、起点漂移、夹爪变化或其他任务改变上下文会要求重算。

## 本地权限边界

`/config/session` 与 `/config/action` 只接受 loopback peer、localhost Host 和精确匹配的 Origin；软件操作另需随机短期会话和递增请求序号。审核 token 绑定会话、版本、120 秒有效期与明确确认。没有硬件解锁接口。私有配置不从静态资源目录提供。

这是软件配置服务的访问边界，不是整个电脑的 CAN 防火墙。现有独立 Rust 网关、命令行探针及旧标签页没有被远程卸载或改写；未来必须把实际总线所有权收归受控执行器。同源恶意脚本、恶意本地进程和伪造本机请求头的转发代理不在当前保护承诺内；禁止把本服务反向代理为公网真实控制端。

此次沿用 `0.0.0.0` 重启的请求被自动审批拒绝，原因是局域网暴露未经明确授权。因此实际重启采用 `127.0.0.1`。其他电脑运行同一界面的方法是克隆源码并在那台电脑启动本地服务，见 README；没有开放当前机器到局域网。

## 备份与恢复（全部仅软件）

- 界面高级区「导出软件备份」：校验和备份，去除设备 ID、设备快照与事件；不是现场原始数据备份。
- 「导入为草稿」：验证 schema/单位/校验和/身份，保留当前 Approved；从备份批准值恢复的内容也降为 Draft，必须重新逐轴审核。导出不自动上传 GitHub。
- 完整备份：停下软件配置编辑后，手动备份整个私有目录到自己的受控存储。历史包含现场信息，勿加入 Git。
- 当前文件损坏/丢失：界面拒绝配置操作，不填默认值；仿真保持可用。先停止本地仿真服务、保留整个私有目录，再选定已核对的本目录历史文件：

```bash
python3 scripts/rebot_config_restore.py \
  outputs/private_config/history/<已核对的版本文件>.json \
  --confirm-software-only
scripts/restart_sim.sh
```

恢复工具验证校验和/结构，备份原损坏文件后原子恢复，不接触电机；重启清空短期会话和旧计划。外部文件不能走此恢复入口，使用界面导入草稿。勿把手工编辑的 JSON、他机映射或历史数值当作已核验真机状态。

## 验证结果

完整摘要与复现步骤见 [验证记录](validation/batch-a/README.md)。

- 后端 9 项测试通过：缺字段、单位、NaN/Infinity、类型、版本冲突、审批重放/会话绑定、原子写失败、权限错误、损坏/丢失、导入、Mock 回读不一致/超时、历史恢复、跨站与直调拒绝。
- 前端 21 个测试文件、95 项测试通过；包含挂载/刷新/演练开关/停止调用不创建硬件连接，旧通用页入口隔离，最终 payload 不可覆盖 op，七轴、软件草稿与逐次确认。
- XYZ 200/150/200 仿真实际到点误差 0.5596 mm；拒绝越界、过期、起点变化、重放与配置变更后的计划。
- 往返抓取、暂停/继续、独占任务、取消、空抓/冻结反馈超时、非法程序整体拒绝通过。
- 连续「国庆快乐」写字通过，最大轨迹形状误差 1.120 mm、文字覆盖误差 1.499 mm，无 MuJoCo 警告。
- 本地 HTTP：软件接口同源会话/重放测试、9 类真实操作拒绝、hardware 到点拒绝、语言前缀/旧路由兼容、资源路径穿越拒绝通过。
- Vite 构建通过，仍有现有大 JS 包提示（约 1.16 MB 未压缩），不影响当前构建。
- 浏览器实际检查：1440×900、1366×768、390px 宽均无横向溢出；XYZ 与 3D 桌面并列、七轴保留、一次展开一轴、临时验证服务的草稿 12 刷新后仍在。该数值只在 `/tmp` 验证实例，不是用户批准增益。
- 浏览器在独立实例完成计算预览并提交仿真执行；实例随后在中断时结束，最终到位以独立数值测试为依据，不虚报浏览器端完整到位证据。

## Git 与回退

用 `git revert <本批提交>` 回退软件，然后重建前端并重启仿真；勿 reset --hard、clean、删除环境或清空 outputs。旧版会恢复历史写入入口，回退不代表可以实际运行它。对已经调好的电机参数没有任何回滚动作，因为本轮没有读取/写入它们。
