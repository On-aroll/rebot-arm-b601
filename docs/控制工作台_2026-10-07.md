# reBot Studio 控制工作台

入口：http://127.0.0.1:8765/ 。这是现有 MuJoCo 服务的新界面，所有运动都作用于物理仿真。当前尚未连接实机。

## 工作台

左侧显示机械臂实时画面、底座坐标系末端位置（mm）、仿真时间、书写轨迹长度，以及六个关节的实际角度、当前插值指令和跟踪偏差。曲线保留最近 30 秒的最大关节偏差；数据来自 `/state`，没有模拟生成的监控数值。实际轨迹长度只统计书写程序记录的路径，不统计所有手动运动。

右侧有三种操作：

- **关节调试**：± 按钮按实际位置点动 0.5°、1° 或 5°；数值框用于编辑六轴目标，点击执行后运动。手动速度上限可选 0.10 / 0.25 / 0.50 rad/s，约束平滑插值指令的峰值速度。此选项不改变预置程序的速度。夹爪单位为单指模型位移 mm，尚未标定真实开口。
- **末端调试**：输入 X/Y/Z（mm），默认“只指定位置”，允许夹爪朝向变化；也可明确选择“保持当前朝向”。点击“检查可达性”只求解并检查路径，不运动；点击执行会重新检查并执行关节插值；不保证末端直线运动，也没有自动绕障。使用 gripper_end 模型坐标帧。
- **任务**：查看名称、完成步骤、当前步骤、错误、任务编号；支持暂停、继续、取消和下载运行摘要。摘要不包含完整逐帧轨迹，服务端完整记录保存在 `outputs/jobs/`。

手动运动、循环演示或动作程序运行时，界面锁定其他运动入口。暂停程序仍持有控制权，须继续或取消后再切换操作。「保持 / 暂停」对手动运动和循环演示结束当前运动，对动作程序则暂停并允许继续。它不是实机急停。

点击「读取当前位置」将反馈填入目标草稿；普通状态刷新不会覆盖正在编辑的目标。数值提交前检查空值、非有限数值和限位；服务器再次检查限位、逆解和运动路径。

画面支持拖动旋转、滚轮缩放，以及机械臂全景和文字正视两个预置视角。复位场景恢复仿真机械臂和物体，并清除书写轨迹，不做实机零位标定。

## 动作程序

提供一笔三维书写、抓取放置、末端画圆、关节运动四个预置。前两个可在 JSON 编辑器查看、编辑、格式化、导入和导出；后两个是服务端内置循环。

「执行此程序」从**当前场景**执行编辑器中的 JSON，先经过服务端完整预检。「复位并运行原始预置」及工作台快捷任务会先**复位场景**，再运行选定的原始预置，忽略编辑器改动。JSON 文件需小于 64 KB。Python 程序仍通过 `scripts/rebot_client.py` 调用同一个执行器。

切换界面或关闭浏览器不会停止服务端程序；运行期间仍可观察反馈和切换视角。反馈超过 2 秒或请求失败时，界面标记过期并禁用运动控件；连接恢复后重新读取状态。这个机制仅锁定浏览器入口，不会自动取消服务端任务，也不是硬件失联保护。请求超时不自动重发运动命令，应先看最新任务和反馈状态。

## 设备与标定

展示当前数据源、反馈新鲜度、用户提供的待核对设备编号，以及电机/轴映射、零位方向限位、工具夹爪、停止与失联处理四项接入准备。实机连接按钮禁用，不打开 CAN 总线。ROS 桥接已有独立验证，但界面还未监测其实时在线状态。

后续顺序：只读实机反馈 → 校准映射并驱动模型 → 单轴低速联调 → 实机轨迹适配器和完整任务。当前不包含电机使能、故障清除、参数写入、自动回零、实机急停链、力控、示教拖动或负载调参。

## 文件与启动

界面：`scripts/dashboard.html`、`scripts/dashboard.css`、`scripts/dashboard.js`；旧界面备份：`scripts/dashboard_legacy.html`。无需新的前端依赖。

```bash
MUJOCO_GL=egl PYOPENGL_PLATFORM=egl ~/.local/bin/rebot-sim serve
```

服务已运行时不重复启动；界面代码改动后刷新页面，Python 服务代码改动后在任务空闲时重启。进程信息见 `outputs/dashboard.pid`，重启前应核对进程命令行。

## 末端位置模式修复

用户目标 `(200, 150, 200) mm` 在旧界面默认保持朝向时求解失败。只指定位置时，从初始姿态和一笔书写结束姿态都能找到满足现有模型限位及路径碰撞采样的解；已完成这两种起点的物理仿真回归。原来显示的残差是 SE(3) 位置与朝向的混合量，不能直接看作毫米距离或超限幅度。

界面新增显式朝向选项、只读可达性检查和持续显示的结果。HTTP `ik` / `ik_check` 接受 `orientation_mode: "position" | "hold"`，坐标单位仍为米；省略该字段仍保持朝向，兼容旧客户端。`Robot.ik` 默认行为及动作程序的工具朝向约束不变。

检查通过只对应当前起点和关节插值路径的离散碰撞检查，不意味着所有起点都能直接过去。逆解未收敛也不构成目标绝对不可达的证明；目前没有多起点搜索或自动绕障。验收：`outputs/tcp_modes_verification.json`、`outputs/tcp_http_verification.json`、`outputs/tcp_ui_verification.json`。
