更新：2026-10-08。适用于这台电脑上的 reBot Arm B601-RS 工程。

**日常入口：http://127.0.0.1:8765/zh/studio/console**

项目目录：`/home/bonvoyage/Desktop/seeed Robotics`。目录名有空格，下面的引号请保留。日常重启不需要下载软件、激活环境或重新编译。

## 一、最快恢复：先打开仿真

打开一个终端，执行：

```bash
cd "/home/bonvoyage/Desktop/seeed Robotics"
bash scripts/restart_sim.sh --status
```

- 如果已经运行且页面正常，直接打开上面的入口，不必重启。
- 如果未运行，或者明确需要重新加载后端代码，执行下面的命令。重启前应先结束或取消当前仿真任务；脚本会关闭旧仿真进程，不会保留任务进度。

```bash
bash scripts/restart_sim.sh
```

等待出现“仿真服务已启动”，通常需要数秒，脚本最多等待约 60 秒。然后在浏览器打开：

[本地 Studio 控制台](http://127.0.0.1:8765/zh/studio/console)

仿真服务在后台运行，启动终端可以关闭。仅做仿真时，到这里即可；实机网关离线不影响仿真程序运行。

**使用本地地址。** 官方网站不包含我们添加的本地动作程序接口。原来的 `/zh/studio/writing` 地址仍是兼容入口，建议收藏现在的 `/zh/studio/console`。

## 二、需要实机反馈时，再启动 CAN 与网关

### 1. 检查连接与 CAN 状态

确认机械臂电源、USB-CAN、USB 数据线和 CAN 接线已经连接。终端执行：

```bash
ip -details link show can0
```

如果接口已经是 `UP`、波特率为 `1000000`，且没有启用 `LISTEN-ONLY` / `LOOPBACK`，一般无需重新配置。

如果电脑刚开机、USB-CAN 刚重插，或者接口处于 `DOWN`，在没有实机动作运行的情况下执行：

```bash
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000 listen-only off loopback off
sudo ip link set can0 up
ip -details link show can0
```

这些命令需要输入本机管理员密码。任一步报错就先处理报错，不继续后续步骤。

检查结果：

- 存在 `can0`，接口标志中包含 `UP`。
- 波特率是 `1000000`。
- `can state ERROR-ACTIVE` 是 CAN 的正常工作状态名称，不代表当前正在报错；还应检查错误计数是否持续增加。
- `BUS-OFF`、持续增加的错误计数或 `Broken pipe` 都需要先排查连接。

这里使用正常通信模式，因为页面读取电机参数需要发送查询。以前排查线路时用过的 `listen-only on` 不适用于正常读写页面。

### 2. 启动实机网关

另开一个终端，先检查网关是否已在运行：

```bash
ss -ltnp 'sport = :9002'
```

如果已有 `ws_gateway` 监听，不重复启动；如果端口被其他程序占用，先确认它是什么，不直接结束陌生进程。

没有监听时，执行：

```bash
cd "/home/bonvoyage/Desktop/seeed Robotics"
./.venv/bin/motorbridge-gateway --bind 127.0.0.1:9002
```

看到 `ws_gateway listening on ws://127.0.0.1:9002` 后，保持这个终端打开，再打开或刷新本地 Studio 页面。这里不需要 `sudo`，也不用先激活 `.venv`。

当前网关以前台方式运行；关闭这个终端或按 `Ctrl+C` 会结束网关。**断开网页或网关不等于电机去使能，也不保证停止实机运动。**

### 3. 检查页面是否恢复

- 仿真画面能加载，状态持续更新。
- 实机网关连接成功，七个电机能逐个读到反馈；刚打开时给它一些读取时间。
- 实际角度、速度上限、位置刚度、电流上限能读到；不要把空值当作 0。
- 保持“演练”开启、总开关关闭，先检查状态。重启检查不需要使能电机、切换运行模式、改零位或写入默认参数。

当前登记的设备配置供排查核对：RobStride；ID 1–3 为 RS06，ID 4–7 为 RS00；通道 `can0`，反馈 ID `0xFD`。这是现有软件配置，并不代替实物铭牌、零位和轴映射验收。

## 三、恢复“国庆快乐”程序

1. 先完成上面的仿真启动与状态检查。
2. 在本地控制台找到“国庆快乐”程序，使用“重置并开始执行”。
3. 观察仿真机械臂、字形轨迹和任务状态；可使用暂停、继续与取消。

**这个按钮当前执行的是仿真程序，不会自动把写字轨迹发送给实机。** 界面中的“程序目标 · 仿真”和“实际角度”来自不同来源，不能仅凭两者同时显示就认定实机已经跟随。

已有一笔三维字形轨迹及多步骤仿真执行能力。实机同步写字还需要完成统一轨迹下发、轴方向/零位/限位验收，以及停止和失联处理验收。不能将“成功重启”当作“已经具备实机自动写字条件”。

### 实机姿态对应

控制台新增「实机与模型对应」，可在六轴反馈完整时显示实机姿态。直达入口：[实机姿态](http://127.0.0.1:8765/zh/studio/console?pose=hardware)。默认官方映射尚未逐轴验收，保存仅影响本浏览器。此功能不使能或驱动实机，见[映射说明](实机模型映射_2026-10-08.md)。

### 指定三维坐标到点

控制台「三维目标点」区：输入 X / Y / Z（毫米）→「计算并预览」→「执行仿真到点」。默认自动调整朝向，控制点为夹爪末端。此功能不需要实机总开关。

实机同步入口尚未开放；原因及验证结果见[三维目标点说明](三维目标点_2026-10-08.md)。更新此功能后，后端必须重启、页面必须刷新，只有构建前端还不能使用新接口。

## 四、启动后怎么确认服务真正正常

`restart_sim.sh --status` 只确认端口与进程，不保证仿真内部仍在更新。如果画面卡住，可在项目目录执行这个只读检查：

```bash
python3 - <<'PY'
import json
import time
from urllib.request import urlopen

for _ in range(2):
    with urlopen('http://127.0.0.1:8765/state', timeout=10) as response:
        state = json.load(response)
    print('后端:', state.get('backend'),
          '更新序号:', state.get('sequence'),
          '错误:', state.get('error') or '无')
    time.sleep(1)
PY
```

应看到后端为 `mujoco`、错误为“无”，两次更新序号增加。连接失败说明服务没有正常响应；错误非空或序号不增加时，先查看日志：

```bash
cd "/home/bonvoyage/Desktop/seeed Robotics"
tail -n 80 outputs/dashboard.log
```

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 页面打不开 | 检查地址是否为本机 `127.0.0.1:8765`；运行 `restart_sim.sh --status`，查看仿真日志。 |
| 画面打开但不再更新 | 使用上面的 `/state` 检查；任务结束后重启仿真服务。 |
| 网关离线 | 查看网关终端是否仍在运行、9002 是否监听；页面连接地址应为 `ws://127.0.0.1:9002`。 |
| 网关已连接，但七轴没有反馈 | 检查电源、CAN 接线、接口是否 UP、1 Mbps、非只监听模式；检查当前通道/型号/ID 配置。网关在线不等于电机在线。 |
| 找不到 `can0` | 用 `ip link show`、`lsusb` 检查接口与 USB 识别情况；重插后接口名可能变化，不盲目重复配置不存在的接口。 |
| 再次出现 `RTNETLINK answers: Broken pipe` | 保留报错，检查 USB-CAN、数据线、扩展坞和供电；这条报错本身不能确定哪个部件坏了。先恢复接口，再启动网关。 |
| 9002 提示地址已占用 | 检查是否已经有网关；不要重复启动或直接批量杀进程。 |
| 参数输入能改，但“应用”是灰色 | 草稿可编辑；实际应用还要求网关在线、总开关开启、新鲜反馈以及有效参数。查看按钮旁的具体原因。不要为消除灰色而随意关闭演练或扩大阈值。 |
| 使能按钮仍不可用 | 除连接与反馈外，还会检查电机速度上限是否超过当前下发阈值；按照界面提示处理，不能把提高保护阈值作为启动步骤。 |
| 页面仍是旧版本 | 先强制刷新 `Ctrl+Shift+R`；仅在修改过前端源码且没有构建时，执行下一节。 |
| 提示旧的机器状态文件过期 | 文件回退通道和网关实时反馈不同；优先看当前网关连接及各轴反馈时间，不能仅据此认定 CAN 离线。 |
