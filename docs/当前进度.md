## 实机接入（2026-10-07 新增）

- **7 个电机全部识别**：ID 1–7，`feedback_id=0xFD`，`responder_id=0xFE`；`motor_id N = jointN`；
  电机 1–3 型号 `rs-06`、4–7 为 `rs-00`（官方 `config/rebotarm_rs.yaml`）。
- **状态读取走参数通道**：官方示例的 `get_state()` 在 RS 固件上返回空
  （官方文档确认：流式帧未被解码）。改用读 `mechPos (0x7019)`，与官方修复方案一致。
- **符号约定 = identity**（`q_urdf = q_mechPos`，不取反）——
  官方文档结论，并经本机实测验证：URDF `joint1` 轴向为 `(0,0,−1)`，
  顺时针（绕 −Z 正向）转动时 mechPos 增大。
- **零位偏移 ≈ 0、无减速比（1:1）**，均有官方与实测依据。
- **`mechPos` 是未归一化的多圈位置**，需 wrap 到 (−180, 180]；
  实测 J6 读到 −196.02°，归一化后 +163.98° 落在模型限位内。
- **实机→仿真镜像已实现并可连续跟随**：`rebot-twin-sync`
  （只读实机、只改仿真模型，零物理风险）。镜像结果与实机读数逐项一致。
- **实机读数已发布到控制台**：`rebot-twin-sync --follow` 每轮原子写
  `outputs/machine_live.json`，仿真服务用只读端点 `/machine-state` 转发；
  控制台并排显示实机、仿真与差值三列，用的是**钳位前**的真实读数。仿真服务不开 CAN。
- **供电已硬确认**：`0x701C` VBUS 实测 48.09 V / 47.93 V / 47.76 V。
