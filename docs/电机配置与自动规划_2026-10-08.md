# 电机配置与自动规划（2026-10-08）

用户明确：每轴模块用于使能/去使能和运动参数调节；关节位置由动作程序与逆运动学计算，不逐轴手填。

## 本次修改

- 电机卡片主区移除目标位置/速度输入、滑块和运动目标下发；位置只读显示为「实际角度」和「程序目标 · 仿真」。夹爪暂无角度目标换算，显示 —。
- 每轴独立编辑并应用三项配置：limit_spd (0x7017)、loc_kp (0x701e)、limit_cur (0x7018)，均为 f32。其适用模式写在字段旁；未读到的值不伪装成 0。
- 草稿输入可直接编辑，写入需要在线、总开关与新鲜反馈；参数必须有限且大于 0；速度不能超过当前配置的下发阈值。
- 配置写入通道只允许以上三个寄存器，不允许位置/速度/电流目标寄存器。真实写入后立即回读，只有一致才标记确认；演练不发参数写入。
- 使能是输出力矩，去使能是释放保持力，均不等于切断供电。网关应答和演练不代表物理使能状态，界面保持「未知」，另记最近下发指令。
- 运行模式放入高级折叠区。单轴手动位置调试仍在 Studio 原「机械臂模式」页。
- 修复 JavaScript 负角度归一化；单步运动校验使用原始计圈角而非 wrapped 值，避免把相隔一圈当小位移。反馈超过 10 秒拒绝新写入（stop/disable 除外）。断线/重连复位总开关。
- 删除原先用 forEach 并发批量写七轴限速的按钮（会与网关互斥冲突）；改为逐轴应用。

## 自动位置计算的边界

现有「国庆快乐」/抓取程序在 MuJoCo 仿真中自动规划并执行六轴目标。新电机配置面板不把这些目标自动发送给实机。
统一实机轨迹执行、映射验收、停止/失联验收与手柄闭环仍待完成。
参数修改可能改变已使能电机的运动特性；本次实施不修改真实参数，不发送使能、模式切换或运动指令。

- MotorModuleCard.test.jsx：可编辑草稿、写入锁定、不提供位置输入、刚度写入无位置指令、演练使能不冒充物理状态。
- motorSettings.test.js：非法参数拒绝、目标寄存器拒绝、速度阈值。
- workspaceFeedback.test.js：坐标、反馈来源及过期处理。
- 共 8 个测试通过；修改文件 ESLint 通过；构建通过。

浏览器只读验收：七轴三项参数均读到；limit_spd=1.0 rad/s，loc_kp=30，ID1–3 limit_cur=57 A，ID4–7=16 A。七轴输入框均可编辑，总开关关闭时应用与使能禁用且有原因说明；浏览器无 error 日志。未测试真实参数写入或使能。

## 后续修正：PP / CSP 限速

逐轴设置现为四项：CSP 速度上限 limit_spd (0x7017)、PP 速度上限 vel_max (0x7024)、位置环刚度和电流上限。新增 run_mode (0x7005) 只读显示。PP 模式1检查 vel_max；CSP模式5检查 limit_spd。不能用CSP速度值为PP或MIT运动作限速证明。

本位置面板的使能门禁只接受已知 PP/CSP 模式和对应有效速度上限；未知或MIT/速度/电流模式给出明确阻塞原因。切换运行模式仍需原有确认，不自动切模式或去使能。两种速度参数应用均不能超过当前下发阈值。
