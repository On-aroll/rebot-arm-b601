# “国庆快乐”一笔三维轨迹

已实现并通过 MuJoCo 物理仿真。四个字在倾斜 60° 的平面上，打印点是机械臂的 `gripper_end` 帧原点。白色短杆及亮点仅用于表示虚拟打印头，没有添加真实打印头质量或夹持接触模型。

## 一笔如何连接

采用手工设计的四字中心线。相交笔画先构成图，沿已画笔画回描，以减少额外连线；不相连的笔画及字之间，沿字面法线向后错开 12 mm 再连接。这些紫色细线也是同一条连续轨迹的一部分，始终可见，没有隐藏的抬笔或瞬移。转角处减速到零仍保持路径连续。

因此是**带回描和空间连接段的一笔字**，不是标准汉字每个笔画只经过一次的欧拉路径。整条高亮线来自每次物理步后的实际末端反馈，不是预先把文字贴在画面上。

## 操作

打开 http://127.0.0.1:8765/ ，点击 **一笔写「国庆快乐」**：自动复位仿真，摆好虚拟夹持姿态，移动到起点，连续书写，最后移开打印点。全过程约 74 秒仿真时间，实际耗时取决于渲染速度。

- **文字正视**：正面查看文字，机械臂半透明，避免遮字。
- **机械臂全景**：显示正常机械臂与三维路径。
- 拖动画面可旋转视角。程序仍可暂停、继续或取消。
- 点击“恢复初始姿态”会清除轨迹；再次运行会重新绘制。

Python 入口（只需系统 Python 标准库，服务需先启动）：

```bash
python3 '/home/bonvoyage/Desktop/seeed Robotics/programs/national_day_one_stroke.py'
```

可编辑程序：`programs/national_day_one_stroke.json`。其中 `trace_path` 包含完整连通的三维点列、线段颜色、固定打印头姿态及速度。网页专用按钮使用启动时预计算的逆解；修改 JSON 后用“运行程序”或 `rebot_client.py` 提交，会重新求解。

修改字形、尺寸、倾斜角与连接深度，可编辑 `scripts/rebot_writing.py` 后重新生成 JSON、验证并重启服务。当前字格 60 mm，字间距 12 mm，整排布局宽 276 mm；这是笔画中心线字形，不是实体填充或逐层切片。

## 验证结果

`outputs/writing_verification.json`：

- 成功完成一条连续轨迹，文字内部抬笔次数为 0。
- 实际轨迹长度约 1.96 m，记录 2352 个点。
- 实际轨迹到设计线段的最大距离约 **1.12 mm**。
- 同时刻实际点与指令点最大误差约 **3.09 mm**，包含运动跟随滞后。
- 对四字每段笔画抽样核查覆盖，最大距离约 **1.50 mm**。
- 无 MuJoCo 求解警告。

`outputs/trace_control_verification.json` 验证暂停续画、取消停止记录与非法路径拒绝；既有抓取等动作回归也通过。最终图片：`outputs/national_day_one_stroke.png`（正视），`outputs/national_day_3d.png`（空间视角）。

本例不生成支撑结构，也不模拟材料、重力下的丝材变形、冷却或粘结；因此只验证无支撑几何路径与机械臂运动，不能据此认定真实材料可以悬空连续成型。实机仍未连接。
