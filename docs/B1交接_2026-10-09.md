## 实现契约

- 配置必须显式给全六轴限位、v/a/jerk、Kp/Kd/前馈/力矩包络、误差及时间约束，单位必须相符。只接受 `synthetic-test-fixture`、`mock-only`、虚拟设备身份；没有真实参数默认值。
- 轨迹使用七次 rest-to-rest 多项式：`35u⁴−84u⁵+70u⁶−20u⁷`。按六轴最严格约束计算每段共同时间，周期向上取整；在各路点位置、速度、加速度、jerk 连续。每个路点停至零速度/加速度/jerk，当前不做不停顿的路径融合。
- 使用原始连续角度，不 wrap 或裁剪。计划绑定起点反馈、配置完整哈希、任务版本、虚拟身份、有效期，且单次消费。起点变化、移动中起步、过期、重复或伪造计划均拒绝。
- 开始时重新读取反馈，首帧取新鲜起点、速度零，不使用 HOME 或历史命令。运行命令含六轴五元组、任务 ID、配置哈希、序号及过期时间，均不持久化为待恢复任务。
- 每轴检查有效性、模式、原始位置、速度、时间/序号顺序、反馈年龄与六轴采样差；监控跟踪误差、估算 MIT 力矩包络、指令年龄、周期超时、确认期限及任务超时。超界拒绝并请求停止，不静默限幅。
- 一个时刻最多一个任务与一个未确认运动帧；等待确认时不堆积新命令，确认太迟不突发追赶。只有末端新鲜六轴反馈满足位置/速度条件且最后命令获确认才能完成。
- 取消先于读取反馈和处理运动 ACK；在读取之后与发送之前再次检查。停止不排在丢失的运动 ACK 后面。不能撤回已经送入 transport 的一帧，取消最迟由下次虚拟 tick 处理。
- 分开记录 `stop_requested`、`stop_sent`、`stop_acknowledged`；`physical_stop_verified` 永远是假。停止失败/负确认/超时进入 FAULT，不自动重试或续传。
- 故障/完成后显式 reset 才能创建新任务；reset 和新进程都清空运行命令。`HardwareDisabledTransport` 永远拒绝；执行器不接受替换成实机 adapter 的子类。

## 复现与重启

从项目根目录，Python 3.10+ 标准库即可运行 B1（无需 CAN/网关/MuJoCo）：

```bash
python3 scripts/verify_mit_mock.py
python3 tests/test_config_protection.py
```

默认报告写入 `outputs/mit_mock_b1/`，不接触 `outputs/private_config/`。重建本次入库证据可指定 `--output docs/validation/batch-b1`。前端依赖按 README 安装后：

```bash
cd external/motorbridge-studio
npm test
VITE_BASE_PATH=/studio/ npm run build
```

网页服务按现有重启指南，仅本地：`scripts/restart_sim.sh --host 127.0.0.1`。本轮已在确认无运行任务后更新该服务。打开控制台仍不自动连接实机。不要为 B1 启动网关、修改 can0、点击“授权并连接只读查询”或运行实机只读脚本。

## 剩余风险与未完成项

1. 真实 MIT 每帧参数来源、固件编码/范围、设备身份及掉电行为未核实；软件批准与合成增益不可替代。既有调定值保持原样。
2. Mock 是理想位置跟随器，无惯量、重力、柔性、背隙、负载/接触与碰撞。力矩估算守卫不等于驱动真实转矩或重力补偿证明。
3. 虚拟 tick 证明调度逻辑，不能证明操作系统实时性、CAN 带宽、串行发六轴帧的偏斜、硬件 ACK/时间戳可信度。进程卡死后必须依赖独立 watchdog；本批未实现真实 watchdog。
4. 虚拟 stop 不定义实机保持、减速或撤力策略；J2/J3 有重力风险，不能把 Mock stop 直接翻译成 disable。物理急停/停止确认仍须另行现场验收。
5. 旧页面白名单只约束本版客户端。旧标签页、其他 SDK/本机程序及原始 Rust 网关仍须服务端权限与总线独占治理；未完成系统级封锁。
6. 所有路点停下，暂不支持移动起点、在线重规划、J7、手柄控制、真实 XYZ/书写联合执行。动态方向/零位/限位映射及 TCP/笔尖标定仍未验收。
7. 只读兼容恢复范围为 RS 与 DM 明确读操作；扫描、流及其他厂商完整状态路径未放开。本次只做静态和 Mock 验证，未开展新的实机查询。
8. 独立新电脑安装、真实 ROS 节点、不同网关二进制兼容性未在本批重测；前端大包仍影响初次加载。

后续可先离线扩展更真实的延迟/负载模型、统一执行层和独立 watchdog 设计。任何真实参数采集或电机试验都需要单独明确范围与现场条件；**本交接不授权下一次真实试验**。
