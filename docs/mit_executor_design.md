# B0：MIT 执行器设计草图（尚未实现真实控制）

B1 独立 Mock 已完成，见 [B1 交接](B1交接_2026-10-09.md) 与验收报告。本页保留 B0 设计及未来实机要求；没有真实执行器或硬件许可。

## 已知与未知

本地 `motorStudioOps` 的 MIT 调用携带位置、速度、Kp、Kd、前馈；本地 SDK 探针 `send_mit` 接口也使用逐帧五元组。它们不证明增益掉电持久化。`loc_kp`、CSP `limit_spd`、PP `vel_max` 属于模式寄存器，不自动映射到 MIT。尚需针对真实驱动/固件版本核对每个字段的编码、范围、转矩常数、反馈协议、异常处理与停止行为。J7 另行核实。

## 接口与不变量

- Plan：唯一 token、设备身份、六轴配置哈希、原始连续起点及反馈时间、模型/任务版本、轨迹、v/a/jerk 约束、预检结果与有效期。消费一次；改配置、模式、姿态、时钟异常或反馈过期均作废。
- RuntimeCommand：每个周期新生成 q_des/qd_des/Kp/Kd/tau_ff、任务 ID、配置版本、序号及失效时间。启动时为空，不持久化、不重放；首帧来自新鲜实机反馈，不能用模型 HOME 或上次目标。
- Feedback：每轴原始 q、可靠时才有 qd、采样/接收单调时间、有效性、模式、身份、真实或未知的使能状态。不以通信 ok 推断到位。
- PreflightResult：逐项报告身份、MIT 模式、增益/力矩来源、物理映射、TCP、限位、v/a/jerk、停止/失联策略、现场授权。任一未知即硬件 LOCKED。
- ExecutionStatus：LOCKED → READY_FOR_SIM → PREVIEWED；未来授权与实机验收后才有 ARMED/RUNNING。故障进入 FAULT 或 STOP_REQUESTED，人工复核后创建新任务，绝不自动续传。
- Transport：先有纯 Mock 和 HardwareDisabledTransport；当前 HTTP 不增加真实 CAN transport。浏览器不负责伺服循环。

## 总线、周期与停止

独立执行进程独占 CAN；状态读数和停止请求通过同一调度器排队，轮询不得自行 close_bus 或切目标。控制周期、允许抖动、查询预算、停止抢占上界均未确认，不填“安全默认值”。停止请求优先于新目标；监控命令年龄、反馈年龄、单轴失步、跟踪超差及任务超时。

必须区分停止请求、发送成功、网关确认和物理安全停止四种状态。异常时是否保持、减速、撤力，须结合 J2/J3 重力负载逐项评审；不能统一 disable。没有独立现场停止手段和明确策略不开展实机动作。

## 权限与威胁模型

当前软件配置 API：仅 loopback peer + localhost Host + 精确同源 Origin，短期随机会话与单次递增序号，审批 token 绑定会话/版本/有效期；不支持任何硬件解锁。这防止普通跨站请求、公开隧道直接访问与误重放，不声称抵御恶意本机进程、同源 XSS 或转发时伪造本机头的代理。

未来硬件授权独立于软件配置审批；服务端须验证操作者、设备身份、一次性任务许可、占有锁和现场运行状态。不可把浏览器 checkbox、localStorage、URL query 当授权。旧网关直接接入须关闭或隔离并纳入同一执行器所有权。

## B1 测试范围（已完成离线实现）

Mock 只使用虚拟时钟/假反馈，无真实 CAN import。覆盖：首帧连续性、v/a/jerk、饱和与转矩边界、模式/版本变更、时间倒退/超龄、旧 token、并发抢占、取消、刷新、单轴失联、周期卡死、停止优先级及确认超时。Mock 发送成功与模拟确认分别断言；不能证明物理停止。当前 A1 mock_apply 只验证软件审核账本的 match/mismatch/timeout 事件，**不是 MIT 伺服执行器**。
