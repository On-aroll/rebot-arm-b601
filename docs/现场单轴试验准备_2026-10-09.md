# 下一步现场单轴试验准备（尚未批准、尚未执行）

最终仍以网页输入 XYZ 后实机到点为目标。当前代码和模拟测试已推进至 P4；单轴现场试验通过之前，六轴实发和网页真实执行不开放。

## 先解决四个具体问题

1. **现场停止与支撑**：操作者是否就在旁边、能立即切断电机电源；J2/J3 是否有可靠支撑，断电会不会下落。请先描述现状，未确认前不要为了测试盲目断电或去使能。
2. **J2 边界读数**：网页最新记录约 −0.31°，模型下限 0°。需要现场确认当前姿态/支撑并重新读取；不将历史偏差写成 offset，不写零位，不裁剪、不扩大限位。若确需机械调整姿态或采用边界容差，另行说明具体操作与证据并取得确认。
3. **静止性**：腕部 mechVel 波动最高约 0.075 rad/s。用新鲜位置/速度序列和现场观察区分运动、振动与反馈噪声；未经验证不能用滤波或提高阈值隐藏它。
4. **独占通信**：首次实发前关闭网页网关查询、旧页面、只读跟随和其他控制器；确认 CAN 正常。当前进程锁与接收者检测只是辅助，不是系统级独占。

以上条件通过前，仅继续只读与仿真，不进行电机运动。

## 拟申请的动作范围

优先考虑 **J1 底座**：只在底座固定、其余关节有支撑、周围留有旋转空间且起点在模型内时进行。选择 J1 是为了避开直接驱动承重 J2/J3；不代表 J1 无碰撞风险。若现场认为其他已支撑轴更合适，应重新形成具体申请。

第一步仅验证使能、当前反馈位置的保持、取消和停止，不直接六轴联合。随后另行确认 J1 从当时新鲜起点向模型正方向 **最多 +1°** 的小幅运动，正常结束不自动返回，不接着执行另一任务。

**拟议工程边界，未批准且不写入配置默认值**：Kp=3、Kd=1、tau_ff=0 沿用用户试验值；运动幅度最多 1°、目标速度最多 0.02 rad/s、加速度最多 0.04 rad/s²、jerk 最多 0.2 rad/s³、跟踪误差最多 1°、软件力矩包络暂拟 0.2 N·m。时间周期、静止/到位阈值及 SDK 超时须结合现场读数和调用耗时形成完整方案，再请用户逐项批准。该组边界不构成安全认证，低增益也不保证能克服静摩擦；若不动，不自动加增益或加力。

预期证据：起点/目标/实际位置分开记录，位移方向一致、幅度不超过已批准范围；无其他轴指令；误差、速度与时间约束未超限。取消/失联后不再发送运动目标，记录撤力请求、SDK 状态及现场是否真正停住。异常时由在场人员使用独立停止手段，不把“网页已断开”当停止。

**这份文档不是当次现场许可。** 因为尚缺支撑/停止确认、J2 边界问题及静止性核实，当前不能发起这一动作。条件确认后，还要明确确认本次关节、参数、幅度与停止方法。
