# 「国庆快乐」末端书写程序

2026-10-16，适用于本目录的 B601-RS / ROS 2 Jazzy / 3002 工作台。

## 直接使用

打开 <http://127.0.0.1:3002/> → **动作程序与示教** → **载入「国庆快乐」**。
页面立即显示四字的彩色规划笔画；导入文件也会生成同样的预览。
点击 **在三维窗口俯视路径**，可在机械臂场景中查看路径的空间位置。

实机连接后，现场确认项本次勾选一次，点击 **使能并执行程序** 即可。
该按钮自动选择完整范围、准备控制、接管、从当前反馈检查整套程序，再启动电机执行。
不需要逐个点击准备、接管或预览，也不要求先运行仿真。导入和切换界面本身不会启动电机。
完成后保持姿态；可暂停、继续或取消，顶部停止按钮沿用原停止/失能流程。

**可选：检查与仿真** 内保留独立预览和试运行。试运行固定使用
`/rebotarm_rs/twin`，采用现有统一执行、暂停、继续、取消与停止机制。
当前顶部若未连接，试运行仍会自行连接仿真。播放虚影需要先连接当前目标并完成路径检查。
保持页面可见，失焦会停止控制。

程序文件是 [`examples/writing/guoqing_kuaile.json`](../examples/writing/guoqing_kuaile.json)。
可用原有 **导入程序 JSON** 导入，也可 **导出程序** 或 **保存到程序库**。
文件只含现有 `pose` 动作；未增加执行器协议，也不需要运行上传代码。

## 导入合同和轨迹

| 项目 | 值 |
| --- | --- |
| 格式 | `schema_version=1.0`，182步，低于250步上限 |
| 机器人 / 坐标系 | `b601_rs` / `base_link` |
| 运动学配置 | `rs-identity-v1` |
| 单位 | 位置m、角度rad、时间s |
| 动作 | 26笔，依次移笔 → 落笔 → 书写 → 抬笔 |
| 文字方向 | +X为字的右方，+Y为字的上方，沿+Z俯视可读 |
| 字格 / 字间距 | 50mm / 12mm |
| TCP书写平面 / 抬笔 | Z=250mm / Z=262mm |
| 实际笔画范围 | X=87–313mm，Y=−291.5–−248mm |
| 固定RPY | 约[−0.28049, 0.50114, −1.19781]rad |
| 关节速度上限 | 0.1rad/s；不是笔尖线速度 |

每条直线按不超过9mm细分，保留折角。每步沿用现有五次关节插补、逐点到位，
没有改为连续匀速书写。从六轴0rad起点，当前完整控制预算下预估254.4秒，
另加执行调度和到位等待；实际起点不同会重新规划入口。

本例为 **gripper_end 的空中书写轨迹**。固定姿态依据可达性选取；没有笔尖TCP、
纸面、接触力或工具碰撞标定。接触书写前须按实际工具和纸面重新定义坐标。
当前验证是URDF几何和模型检查，不能当作纸面精度、工具避障或实机运行验收。
实机执行按钮会自动从新鲜反馈重新检查程序，仍遵守项目原有现场许可要求。

## ROS / RViz 高亮

```bash
cd /home/bonvoyage/Desktop/rebot-b601-doc-replica/ReBot_Arm_DigitalTwin_RS
bash scripts/preview_guoqing.sh
```

此命令启动独立的可视化节点和专用RViz配置，固定坐标系为`base_link`，默认俯视四字。
关闭RViz时会一并结束该可视化节点。

| 话题 | 类型 | 用途 |
| --- | --- | --- |
| `/rebotarm_writing/strokes` | `visualization_msgs/msg/MarkerArray` | 26条独立LINE_STRIP，按字分色，只连接落笔段 |
| `/rebotarm_writing/tcp_path` | `nav_msgs/msg/Path` | 完整182点，包含抬笔和移笔，默认关闭显示 |

RViz显示由离线逆解后的 **关节插补FK采样** 构成的规划轨迹；不是接收过的真实TCP轨迹，
不是用文字标签叠出的字。网页SVG和三维线条显示JSON中的规划坐标；播放时用执行器
反馈的步骤序号高亮已走过、当前和后续的规划段。该高亮不表示实测笔尖落在路径上。
修改JSON后原高亮立即清空，重新导入或检查后再生成。

可视化节点仅发布上述两个显示话题，不持有CAN、控制租约或命令发布器。
QoS采用Reliable / Transient Local，且每秒重新发布，支持后打开RViz及现有rosbridge。

## 重新生成和验证

```bash
source scripts/rs_env.sh
python3 scripts/generate_guoqing_program.py
```

生成器手工定义单线笔画，不依赖字体轮廓；输出JSON、FK采样路径以及网页内置示例。
只构造运动学模型，不连接硬件。

验证记录在`outputs/writing/`：

- `verification.json`：182步、26笔，所有点的固定姿态IK、名义关节限位、官方持续额定
  重力包络和采样自碰撞通过；笔画内每对关节点采样8段，最大直线偏差约0.0923mm、
  离面偏差约0.0707mm。这是模型采样结果，并非连续误差保证或实机测量。
  除入口外的抬笔移笔段各取21个FK样本，最小离面高度约9.90mm；12mm是端点抬笔高度。
- `compile.json`：使用原`compile_program`及`TwinControl._goal_duration`整套编译通过，
  检查约0.67秒，未触及25秒超时，估计254.4秒。
- `ros_transport.json`：通过现有rosbridge收到26个Marker、858个笔画FK采样点及182个
  Path点，坐标系均为`base_link`。
- `simulation.json`：通过网页原有「在仿真中试运行」导入同一文件，运行于`/rebotarm_rs`，
  反馈来源为`/rebotarm_rs/mujoco/joint_states`；控制器最终报告`completed`、182/182、
  「全部步骤已确认到达」。只读记录器从第63步开始保存状态，最终完成状态与网页一致。
  `workbench-completed.jpg`保存四字高亮与完成进度；仿真结束后原入口已自动释放控制。
- 既有程序引擎41项测试、网页输入/重置20项测试、工作台API6项测试通过。

以上生成与仿真批次没有向真实机械臂发送使能、运动、重置或参数写入。
后续一次经用户确认的实机启动在首笔前超时并停止；不能将仿真完成当作实机完成。
