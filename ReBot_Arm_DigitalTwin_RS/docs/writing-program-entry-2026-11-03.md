# BIT103 与国庆快乐统一入口

用户反馈找不到 BIT103，希望与国庆快乐放在同一程序界面，并在此调整法线与书写平面。

## 原因与修改

原 BIT103 在本机程序库 `outputs/workbench/programs/` 中仍有两个历史条目：旧世界 XY 平面、旧夹爪轴平面。两条因实际工具方向/笔尖/碰撞体未标定，已转换成零秒等待并明确标停用，原路线存档保留。11 月 3 日上午新增的可调模板入口曾在编辑器上方，但侧栏描述只列国庆快乐，程序库只列用户保存项，未提供模板项，入口容易混淆。

此次将两按钮放进“动作程序 → 书写程序 · BIT103 / 国庆快乐”的同一区域，默认展开。法线、腕部偏角、文字旋转、抬笔、尺寸、原点偏移及方向示意均在此卡片中，随后才是通用程序编辑器。选择文字后仍按各自偏好显示设置，生成结果填入同一编辑器、可保存至同一本机库。

本机程序库新增永久的“书写模板 · 设置平面后生成”分组，包含 BIT103、国庆快乐；“载入 / 打开设置”根据所选项打开模板设置或载入原保存程序。模板选项不依赖保存项列表是否成功返回，不自动载入停用路线，不生成目标或启动电机。两旧条目继续保留在“本机保存的程序”，没有重写。
