## 从页面开始

1. 在工程目录执行 `./rebotarm start all`，打开 <http://127.0.0.1:3002/>。
2. 选择「实机 + 数字孪生」，点「连接实机反馈」。连接只读取编码器。
3. 在「控制范围」中选择「完整控制 · 模型限位内 / 持续保持」。页面出现「准备完整控制」及完整范围说明。
4. 核对现场方向、零位、限位和独立断电条件，勾选现场确认和「允许网页向 RS 真机发控制」。
5. 点「准备完整控制（不使能）」，再点「接管控制」。这两步尚不使能。
6. 点「启动电机保持（使能）」：从最新实测姿态预装载目标并请求六轴使能保持，无需先解算坐标。
   也可以直接执行轨迹或手动控制，由首个运动输入启动 CSP。两种方式共用全部后台检查与时限。
7. 结束时点顶部「停止 / Esc」，等待「已失能 · 只读观察」。之后可切回小幅模式或断开 ROS。

代码更新后，先在页面断开再连接实机反馈服务，再刷新页面。运行中的旧 Python 进程不会自动加载新模式。
每次重启反馈服务都默认回到小幅模式；完整模式不自动续接，也不自动恢复上次运动。

## 操作状态乱了

点顶部「↻ 重置控制状态」即可停止、释放并清空输入/预览，按原快照核对临时参数恢复。
重置完成后重新准备、接管；不需要先执行小幅运动。失败会显示原因并继续锁定，不能用重置代替机械排障。
见[一键重置说明](重置控制状态.md)。

## 控制方式

| 方式 | 操作 |
| --- | --- |
| 坐标到点 | 「填入当前位置」→ 修改位置 mm / 姿态 ° → 「计算并预览」→ 观察目标虚影 → 「执行预览轨迹」 |
| 键盘 | 选择「键盘 / 按钮」，按住空格；W/S 为 X，A/D 为 Y，R/F 为 Z，U/O 为 Roll，I/K 为 Pitch，J/L 为 Yaw |
| 屏幕按钮 | 按住对应轴正负按钮，松开保持 |
| 标准手柄 | 先松开摇杆和 RB；按住 RB/R1 才运动。左杆 X/Y、十字键 Z、右杆 Pitch/Yaw、LT/RT Roll，LB/L1 为四分之一精细速度 |

姿态以基座坐标系为参考。坐标默认「仅位置（自动选择姿态）」：约束 XYZ，预览后显示解算出的 RPY，必须先观察虚影。
也可主动选择「保持当前姿态」或「使用输入的 RPY」；这两种约束严格执行，不会自动改成自由姿态。
靠近 J2/J3 下限时，部分平移方向无法同时保持原朝向。此时页面显示位置/姿态残差；若同一坐标仅位置可解，
会出现「改为仅位置并重新预览」按钮，点击仍只计算。所有 IK 失败均不启动运动，也不会使能。
逆解采用带关节边界的多起点优化；“未找到解”不等于已证明几何不可达或处于奇异点。
按住空格/RB并松方向输入时平滑减速到保持；松开空格/RB或屏幕按钮立即请求保持。失焦、隐藏网页或连接中断会释放控制。
仿真实色模型显示编码器反馈，目标虚影表示计划目标；右侧相机单独连接，用于人工对照。

页面的电机状态区分「只读 / 已准备 / 已接管但未使能 / 正在使能 / 使能已下发」。
本机固件没有可靠的独立使能状态读回；“CSP 已启动”表示驱动完成使能流程，实际保持力矩须现场观察。
编码器能读到说明通信存在，不能用它单独证明电机已输出力矩。这里的使能也不能接通外部电源。

## 两种范围

| 项目 | 小幅试机（默认） | 完整控制 |
| --- | --- | --- |
| 相对接管起点的限制 | 每轴 0.5° | 取消，使用下面的模型限位 |
| 关节速度设置 | 直接输入 0.005–0.02 rad/s | 直接输入 0.005–设备实际生效上限；本机目前 1.0 rad/s，官方网页上限 1.5 rad/s |
| 初始关节速度 | 0.01 rad/s | 0.1 rad/s（原0.02的5倍） |
| 平移速度 | 0.5–3 mm/s，默认 1 | 0.5–40 mm/s，默认 25 |
| 姿态速度 | 0.5–3°/s，默认 1 | 0.5–20°/s，默认 10 |
| 首次使能起的最长时间 | 15 秒 | 无固定时长；主动停止/失能或异常时结束 |
| 最大参考与编码器跟踪差值 | 0.6° | 3° |

平移/姿态速度最终受关节限速约束，奇异位形附近可能较慢或被拒绝。
小幅模式显示剩余秒数，到时停止并失能。完整模式取消固定使能时长；到点或松开输入后继续原地保持，
主动停止、失能、重置或控制连接/反馈/保护异常时才失能。仍要求网页保持前台连接与有效心跳；失焦/断连会停止，
不会离线追赶旧目标。软件使能与机械臂物理供电是两件事，外部断电开关由现场操作。
预计轨迹时间超过小幅模式剩余时长时拒绝执行；完整模式不设会话总时长预算。准备、占用或停止清理期间不能切换范围。

| 关节 | 当前模型角度范围（约） |
| --- | --- |
| J1 | −150° 至 +150° |
| J2 / J3 | 0° 至 179.9° |
| J4 / J5 | −90° 至 +90° |
| J6 | −179.9° 至 +179.9° |

实际判定使用模型中的弧度值。起点最多 1° 的既有边界容差仅允许保持或向范围内恢复，不扩大目标范围。

坐标到点使用关节速度上限；平移/姿态滑块用于键盘和手柄。完整模式的三项默认值按用户要求提高5倍，
现完整方案采用官方轨迹加速度4rad/s²，坐标轨迹jerk30rad/s³。短距离耗时仍受路径和跟随能力影响；实际额外负载尚未标定。

停止、失焦/隐藏或断开仍会撤去电机驱动力。页面保存「上次网页停止请求」，重新加载后也可查看。
控制器报告 `reason` 为实际中断原因，`browser_stop_request` 为收到的网页诊断请求；诊断不控制电机。
本次旧日志没有具体网页来源，不能据此确定是失焦还是手动停止。详见[运动中失能与5倍速度](运动中失能与五倍速度_2026-10-16.md)。

启动时两次静止编码器读数不要求完全一致；仍限制起点变化≤0.1°，每轴按最新实测值预装载。
坐标轨迹在使能后从固定保持参考开始，并重新检查路径与时长，避免追赶旧预览起点。
见[起点边界误判修复](起点边界误判修复_2026-10-16.md)。
J7 夹爪尚未接入此执行通路。

## 保留的后台检查

- 独占 CAN；当前控制会话持有租约，旧网关不能同时写入。
- 输入年龄、序号、250 ms 输入超时、700 ms 网页心跳、300 ms 电机命令窗口、600 ms 反馈年龄检查继续有效。
- 保留电机内部 PID，不写零位、flash，不自动回零。
- 完整模式临时速度限制取官方网页1.5rad/s与设备原值的较小值；限流J1–J3为57A、J4–J6为16A，限矩分别36/14N·m，依据官方RS预设。持续重力按额定11/5N·m检查，峰值不是持续输出保证。
  若设备现有限制比提案更低，拒绝提高；不会覆盖设备较低限制。
- 检查名义重力力矩和模型自身碰撞。长预览以最多 1° 关节间隔采样，运行中逐次检查目标。
  因负载、模型包络或自身碰撞被拒绝的目标不会执行；完整范围不意味着任意空间点都可达。
- 停止先失能、核对状态与连续停稳，再恢复本次模式/限速/电流/力矩快照，不恢复旧位置目标。
  停稳/恢复未确认则锁住后续控制并报告。

网页停止是软件停止，不能代替独立物理急停。失能会撤去驱动力，重力下姿态可能变化，现场应有既定机械支撑与断电条件。
没有环境自动避障、相机闭环定位或硬件时钟同步。实际反馈、网络和渲染有延迟，不能视为零延迟同步。

## 异响或停止清理失败

如出现异常声或疑似卡滞，先停止，勿在使能保持时强行手转。若显示“停止/参数恢复待核查”，
页面仅保留反馈并锁定使能；重启不会解除。模式 5 是 CSP 算法模式，不代表仍使能。
须先核查机械状态，再按本次真实快照核对失能、停稳与参数恢复，不能靠反复使能或强制切模式绕过。
详见 [实机异响与模式残留排查](实机异响与模式残留排查_2026-10-16.md)。
