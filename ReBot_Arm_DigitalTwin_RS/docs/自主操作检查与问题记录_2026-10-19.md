# 自主操作检查与问题记录（2026-10-19）

## 1. 结论和本轮边界

**实机只读检查完成，实机运动被恢复锁阻塞；仿真操作流程完成。不能把本轮结果写成实机运动验收通过。**

用户确认在现场，允许每轴运动不超过 180°。这不是解除模型限位、恢复锁或指定任意空间路径的许可。本轮实际没有请求实机准备、接管、使能、运动、重置、参数写入或 CAN 重配，也没有重启任何控制服务。

实机当前为 `RECOVERY / IDLE`、无控制所有者、未准备。六轴运行模式均为 5；**运行模式不等于使能状态**，不能仅凭它声称电机正在出力或已经失能。驱动明确报告：当前模式非 0，缺少事故前完整参数快照，不能覆盖默认值恢复。

实机页面用 `127.0.0.1:3002` 的独立检查标签，只连接既有驱动；仿真用 `localhost:3002` 的独立网页配置，明确选择 `/rebotarm_rs`，避免改动用户原网页的目标选择与草稿。未使用 MotorBridge 另开 CAN 所有者。

## 5. 恢复后建议的实机顺序

1. 先解决原始快照来源和恢复锁，核查机械状态与 J2 边界；确认新的只读状态与实际加载版本。
2. 首轮恢复后的运动从小幅、低速、单次动作开始，检查方向、暂停保持、跟踪与停稳记录。用户的 180° 上限是本轮授权边界，不是首个测试目标，也不能覆盖各轴更小的模型限位。
3. 在已确认的空旷区域，分别验坐标到点与 TCP 拖动到点；记录目标、实际位置、峰值误差、到位时间和停稳后的变化，再逐步扩大范围。
4. 同一控制链路验证 J7，采集空夹、工件、夹具误接触和滑落数据；用现有离线工具评审阈值。电机接触证据不能直接宣称工件可靠夹住。
5. 再实现并验收官方完整视觉 Demo，然后叠加可靠夹持判定。电弧焊仍是独立的后续集成与工艺验证任务。
