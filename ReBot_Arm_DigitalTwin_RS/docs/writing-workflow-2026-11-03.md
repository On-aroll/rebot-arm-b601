# 书写程序的五步使用框架

用户需要：手动移动到一个位置，选末端腕部参考轴并输入偏角，看到偏转后的轴线及其法向平面，确认后在该平面执行程序。BIT103 与国庆快乐共用此流程。

## 使用流程

1. **摆位与记录。** 用户先手动调整末端的位置和朝向，再点“记录当前末端位姿”。只读新鲜的六维反馈，显示记录时间、TCP 位置和姿态，不发运动。当前程序运行/暂停时不录新平面。
2. **设置法线和平面。** 选择腕部 link6 的带符号 XYZ 轴，设置固定腕部 XYZ 偏角。偏转后的 N 是执行平面的法线；平面经过记录时的模型 TCP，可加腕部坐标原点偏移。图中灰色参考轴、黄色偏转 N、绿色平面、R/U 字向、粉色抬笔分别显示；抬笔正负与文字旋转独立。调角仅改变规划平面，末端姿态仍保持记录值，不自动转腕。
3. **确认并生成。** 用户核对原点、字的右/上方向、抬笔一侧及尺寸，再明确点击“确认此平面并生成程序”。冻结本次程序，填入现有编辑器，此时没有准备、接管、使能或运动。平面固定在基座坐标，手臂后续移动不会带它漂移；要换平面须重新记录。
4. **检查与预览。** 同页按钮走原程序检查器，检查所有步骤的逆解、范围、重力与机器人自碰撞。通过后可播放虚影；虚影不发运动。重新检查先撤销上次通过状态，迟到或失效的结果不会恢复“可执行”。
5. **执行。** 只允许本次确认且检查通过的程序进入执行准备；共享执行按钮同样校验，不能绕过本流程。执行器仍按实时起点重新检查，再由唯一控制通路执行。原有进度、暂停、继续、取消保留在下方通用程序区。

BIT103 总宽仍不超过 100 mm。保存偏好与保存程序都不保存本次确认资格；重开页面或载入保存的书写程序时可查看原规划，但须重新记录、确认、检查。

## 一致性约束

- 当前确认绑定实际步骤、书写平面、尺寸/速度与程序坐标信息；仅更名不会改变几何。
- 修改轴、偏角、尺寸、文字、原点、重新记录或编辑程序，均撤销确认、旧路径和预览；切换控制对象要求重新记录。用户进入书写设置后，也不能误按共享按钮执行编辑器中的旧通用程序。
- 设置变化使正在等待的旧路径结果失效；执行准备期间变化会阻止延迟开始。轴、偏角、尺寸等书写设置本身不发送停止、失能或新运动；通用程序编辑器取消准备沿用原暂停/保持逻辑。
- 载入通用程序可回到原通用程序流程；载入书写程序不能从文件取得本轮确认。
- 手动摆位是已有手动控制功能，不由“记录”或“确认”按钮代替。页面无新鲜反馈时不能假造当前位姿。

## 实机范围

真实笔尖、笔杆方向、工具碰撞体以及纸面/现场障碍尚未完成标定。本次仍生成 `preview_only=true` 的几何程序；平面确认不是工具标定，也不替代现场控制确认。网页在实机准备/接管/使能之前拒绝此类书写执行。现有自碰撞检查不能证明笔尖、工具或桌面安全；工具和环境模型补齐后才能单独验收真正接触书写。

本轮未启动或连接 ROS、CAN、实机驱动、相机，未使能、失能或运动；不沿用上午的旧设备状态作为当前证明。
