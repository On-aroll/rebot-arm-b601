## 书写设置与方向约定

入口为“动作程序 → 国庆快乐 / BIT103 · 设置书写平面”。可分别设置：

- 法线取腕部 `link6` 的 ±X、±Y、±Z，初次不猜测工具轴；
- 依次绕固定腕部 +X、+Y、+Z 偏转，正角按右手规则；
- 文字绕 +N 旋转，以及独立的 +N/−N 抬笔方向；
- 总字宽、字高、抬笔距离、沿腕部 XYZ 的平面原点偏移。

先“记录当前末端位姿”，再选择方向、生成程序。记录只读取新鲜反馈，不启动电机。平面原点默认是当时的模型 TCP `gripper_end`；记录后固定，不追随随后末端运动。腕部旋转从实际 URDF 的 `link6 → gripper_end` 固定变换反算，禁止把 TCP 轴直接冒充腕部轴。

无偏转、无文字旋转时，右/上向量约定如下；偏转后仍保持 `R × U = N`：

| 选定法线 | 字的右方 R | 字的上方 U |
| --- | --- | --- |
| +X | +Y | +Z |
| −X | +Y | −Z |
| +Y | +Z | +X |
| −Y | +Z | −X |
| +Z | +X | +Y |
| −Z | +X | −Y |

从 +N 一侧看文字为正向。翻转 N 会改变 U，应核对示意；改变抬笔正负不镜像文字。图中左侧标腕部三正轴，右侧分别标 R、U、黄色 +N、粉色虚线抬笔箭头。落笔方向与抬笔相反；数字向量也以基座坐标显示。图采用固定基座斜视，不等同现场相机视角。

设置以 `rebot-writing-settings-v1` 分文字存入本浏览器/站点的 localStorage；不识别同浏览器中的不同自然人。正常重开保留轴、角度和尺寸，但不默默复用旧现场位姿；须重新记录。导出/保存的程序携带冻结平面元数据，再载入可查看原规划。修改设置使旧本地路径检查和虚影失效，需重新生成。

两套笔画沿所定义平面生成，姿态冻结，移笔沿选定抬笔方向。BIT103 默认总宽 90 mm，严格不超过 100 mm；新生成方案仍走原整套 IK、限位、重力和机器人自碰撞预览。

**实际笔尖、笔杆轴以及工具/纸面碰撞几何尚未标定**。设置原点偏移不代表已完成这些标定；产物带 `preview_only=true`、`pen_tip_calibrated=false`，网页在准备/接管/使能之前拒绝实机执行。保留旧库中零秒等待的停用书写项，不恢复旧水平面或夹爪轴程序，不自动书写。下一步需补齐真实工具标定与环境碰撞模型，才能另行验收实机书写。
