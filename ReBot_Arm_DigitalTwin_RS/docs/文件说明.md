## `rebotarm_ros2_RS/`

这是 ROS 2 Jazzy 工作区。`src/` 是源代码，`build/`、`install/`、`log/` 是 colcon 生成的
构建产物，`.venv/` 是项目 Python 虚拟环境。

### ROS 包

| 包 | 作用 |
| --- | --- |
| `rebotarmcontroller` | 真机 RS 控制器、Fake Driver、CAN/SDK 适配、反馈缓存、轨迹、重力补偿和 Leader 控制。 |
| `rebotarm_bringup` | 真机、Fake Driver 和基础 ROS 节点的 launch、参数、URDF 和 RViz 配置。 |
| `rebotarm_mujoco_rs` | RS 专用 MuJoCo 物理仿真、ROS 同步、场景相机、颜色检测、任务服务和腕部相机。 |
| `rebotarm_msgs` | ROS action、message、service 定义，包括 Pose、关节、夹爪和 Leader 接口。 |
| `rebotarm_agent` | MCP 抓取 Agent 和可选 text-agent HTTP 服务。 |
| `rebotarm_moveit_config` | MoveIt 运动规划配置、URDF/Xacro、控制器、关节限制和 RViz。 |
| `rebotarm_moveit_demos` | MoveIt 方形轨迹、取放演示及对应 launch。 |

### 主要源码文件

- `rebotarmcontroller/fake_rs_driver.py`：隔离的 `/rebotarm_rs` 仿真控制器，不访问 CAN。
- `rebotarmcontroller/rebotarm_controller.py`：真实 RS 控制器节点入口和状态机。
- `rebotarmcontroller/hardware_manager.py`：SDK、电机、反馈缓存和安全状态管理。
- `rebotarmcontroller/motion_profiles.py`、`trajectory_profiles.py`：速度、加速度和 jerk 约束。
- `rebotarmcontroller/ros_actions.py`、`ros_services.py`、`ros_publishers.py`：ROS 接口层。
- `rebotarmcontroller/leader_*.py`：Leader 设备扫描、采样、标定和跟随策略。
- `rebotarm_bringup/launch/fake_rs_bringup.launch.py`：Fake Driver 的 ROS 启动描述。
- `rebotarm_mujoco_rs/rebotarm_mujoco_rs/mujoco_sync.py`：MuJoCo 状态与 ROS 关节状态同步。
- `scene_camera.py`、`scene_detector.py`：俯视相机和颜色方块检测。
- `task_server.py`：仿真抓取、放置和任务动作接口。
- `wrist_camera_selector.py`、`wrist_cameras.py`：腕部相机模型选择与加载。
- `rebotarm_agent.py` 下的 `rebotarm_mcp_server.py`、`rebotarm_text_agent.py`：MCP 工具和自然语言服务。

`third_party/reBotArm_control_py/` 是随工程保存的 RobStride 控制 SDK 源码；`third_party/README.md`
记录来源版本。它不是运行时重新 clone 的子模块。

`rebotarm_ros2_RS/README.md`、`README_zh.md` 和 `API_zh.md` 分别是英文总览、中文运行说明
和接口说明；各 ROS 包中的 `package.xml` 声明依赖与安装元数据，`setup.py` / `setup.cfg` 声明
Python 包、入口命令和测试。`config/`、`description/`、`launch/`、`rviz/` 和 `models/`
分别保存参数、机器人描述、启动文件、RViz 配置和 MuJoCo 模型。

## 生成目录和不应手改的内容

- `rebotarm_ros2_RS/build/`：colcon 编译中间产物。
- `rebotarm_ros2_RS/install/`：colcon 安装空间，运行时由 `rs_env.sh` 加载。
- `rebotarm_ros2_RS/log/`：colcon 日志。
- `rebotarm_ros2_RS/.venv/`：Python 虚拟环境。
- `__pycache__/`、`.pytest_cache/`：Python 运行和测试缓存。

这些目录由安装、构建或测试自动生成。修改功能时编辑 `src/`、`scripts/`、网页 `public/` 和
文档源文件；不要直接修改 `build/` 或 `install/` 中的复制文件。

## 启动关系

```text
rebotarm start all
  -> scripts/quick_start.sh
     -> scripts/start_rs_sim.sh
        -> rebotarm_bringup/fake_rs_bringup.launch.py
        -> rebotarm_mujoco_rs/mujoco_rs.launch.py
        -> rebotarm_agent/rebotarm_mcp.launch.py
        -> rosbridge_server (9090)
     -> reBotArm_simulator-RS/server.js (3002)
```

真机路径单独使用 `rebotarm start rs`，命名空间为 `/rebotarm`，受确认变量保护；它与一键启动
安全仿真路径保持分离。

| `docs/` | 原有 Studio / 动作程序 / CAN / 实机只读通信的中文记录；`项目重启指南.md` 是旧工作台入口。 |
| `programs/` | 根工程动作程序样例，包含 JSON 编排和 Python 往返搬运、书写程序。 |
| `models/` | 根工程 MuJoCo 场景参考文件。 |
| `scripts/` | 旧 Studio 后端、仿真、CAN 诊断、ROS 桥、动作程序 HTTP 接口和安装脚本。 |
| `tests/` | 根工程 HTTP、ROS、网关、动作程序和 Studio 路由验收脚本。 |
| `outputs/` | 根工程测试报告、诊断、轨迹和演示产物。 |
| `external/motorbridge-studio/` | MotorBridge Studio 前端源码和构建配置；控制台 UI 主要在 `src/`。 |
| `rebotarm_ros2/` | 原始 ROS 2 文档和上游工程参考副本，供对照 RS 集成，不是当前一键启动入口。 |
| `ReBot_Arm_DigitalTwin_RS/` | 当前 RS 数字孪生、ROS 2、MuJoCo 和 Web Simulator 的完整工程。 |

根工作区中的 `scripts/restart_sim.sh` 启动旧 Studio 仿真，`scripts/same_sim_ros.launch.py` 将旧
仿真状态发布到 ROS 2；它们与 RS 工程的 `rebotarm` 入口是两条独立链路。不要把旧工程的
`/rebotarm` 目标误当成 RS Fake Driver 的 `/rebotarm_rs`。

## 常见单文件职责

上层 `scripts/` 中，`rebot_sim.py` 是 MuJoCo 服务核心，`rebot_core.py` 提供运动学和安全检查，
`rebot_program.py` 执行动作程序，`rebot_ros_bridge.py` 负责 ROS 桥接，`rebot_client.py`、
`rebot_point.py` 和 `rebot_writing.py` 是对应的 HTTP / 命令行客户端；`rebot_can_*.py` 和
`diagnose_can_usb.py` 只做 CAN 诊断或只读探针。`dashboard.html`、`dashboard.css`、
`dashboard.js` 是旧工作台网页。

`external/motorbridge-studio/src/` 中，`components/ConsoleWorkspace.jsx` 是虚实联调控制台，
`components/MotorModuleCard.jsx` 是单电机卡片，`hooks/useMotorGateway.js` 是网关和三道写入闸门，
`styles/console-workspace.css` 是控制台样式；`package.json`、`vite.config.js`、`vitest.config.js`
和各类 lock 文件只负责依赖、构建和测试配置。

上层 `rebotarm_ros2/` 中，`cn_reBot_Arm_B601_RS_ROS2_Integration.md` 是 RS ROS 2 集成参考，
`cn_reBot_Arm_B601_DM_ROS2_Integration.md` 是 DM 对照参考，`API_zh.md`、`README_zh.md` 和
`README.md` 是对应的接口与运行说明；`media/` 只存文档图片。
