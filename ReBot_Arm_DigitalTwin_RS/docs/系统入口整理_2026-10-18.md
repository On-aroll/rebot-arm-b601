# 系统入口整理

原来的三个入口都进入同一个系统面板，分步准备和重置仅展开该面板中的不同小节，因此会看到相同详细界面。

现在改为三个独立页面：

| 左侧入口 | 页面内容 |
| --- | --- |
| 连接与服务 | 控制对象、连接反馈、网页/ROS/驱动状态、刷新检查、项目启动台链接、高级连接与显示设置 |
| 分步准备与接管 | 控制范围、控制许可、准备、接管、使能保持、暂停释放、限制依据 |
| 重置与维护 | 支撑提示、重置按钮、清理与参数恢复结果 |

连接高级设置已收进连接页，左侧不再单列入口。切换页面会隐藏其他详细面板并关闭高级侧栏。工具栏排序沿用原有标识和本机保存结果，已移除入口的旧排序记录会被忽略。

管理页面隐藏重复的一键手动操作和普通任务就绪提示；错误提示、顶部暂停/失能入口及所需现场确认继续显示。所有控制按钮仍保留原有ID、事件及使能校验；这次只改界面组织，不自动连接、接管、使能、重置或运动。
