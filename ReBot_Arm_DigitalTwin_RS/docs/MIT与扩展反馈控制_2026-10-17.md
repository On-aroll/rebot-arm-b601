# MIT与扩展反馈控制

## 接入结果

3002 页面上方的「共用运动配置」新增六轴 CSP / MIT 驱动选择及逐轴 MIT Kp/Kd。
坐标到点、键盘、手柄、TCP、动作程序和反馈控制器继续共用同一个 CAN 所有者、轨迹平滑与运动检查。
完整模式默认 Ruckig + CSP；驱动重连仍默认 CSP。MIT 参数会保存，选择 MIT 本身不使能。
小幅试验及 J7 沿用既有 CSP 方案。

「控制与调参」提供六种内置反馈控制器和本机 HTTP 扩展：

| 控制器 | 实际实现 | 独立调参 |
| --- | --- | --- |
| P / PD / PID | 位置误差到速度参考；微分取测量速度，PID 条件抗积分饱和 | 六轴 Kp/Ki/Kd、滤波、积分贡献上限 |
| 增益调度 PID | 根据误差大小，用平滑曲线调整逐轴 Kp；远端与近端连续过渡 | PID 参数、远端倍率、误差尺度 |
| LADRC | 一阶位置积分模型的离散扩张状态观测器，观测极点按实际反馈间隔离散化；使用平滑器速度参考估计总扰动 | 控制带宽、观测带宽、输入增益、扰动估计上限 |
| 线性 MPC | 关节积分预测模型，有限时域二次代价；盒约束坐标下降求解，投影残差收敛后才采用首个控制量 | 4–24 预测步、位置误差/速度/速度变化权重 |

内置控制器以 5–20 Hz 新鲜反馈计算；CAN 参考沿用目标 20 ms 的既有调度，不宣称硬实时或官方 MIT 示例的 200 Hz。
MPC 对每步速度施加保守盒约束，保证积分模型的预测位置不越界；实际限位、路径、自碰撞、模型重力与跟踪检查仍由共用执行器负责。
模型没有辨识整臂动力学和负载，不保证最优物理控制效果。LADRC 的速度输入是主机平滑器参考，不是实测驱动力。
没有附带神经网络或强化学习训练模型；外部扩展可接入实际算法与模型，界面不会把空实现作为内置选项。

各算法独立保留草稿和多份命名档案，导入/导出配置；示例见 `examples/control/{scheduled_pid,ladrc,mpc}.json`。
运行监视增加当前调度 Kp、ESO 扰动估计、MPC 迭代数及残差，调参记录同时导出所用驱动、MIT 增益、轨迹参数与误差统计。
试算不发送运动；只有显式启动才让反馈控制器接管固定关节目标。手动/程序仍按自己的目标生成参考，不会偷偷启用 PID 或 MPC。

## MIT接入方式与边界

官方独立示例的 connect 会切换模式并使能，stop/通信故障会失能或回零。当前接入复用本项目的生命周期，不调用该自动流程。
MIT 位置 PD 帧为 `[q_ref, 0, Kp, Kd, 0]`，速度和力矩前馈固定为零；这不是主机全动力学力矩控制，也不是力传感闭环。
默认 Kp `[50,150,150,50,50,50]`、Kd `[3,10,10,5,4,4]` 来自锁定 Seeed SDK YAML，只允许向下调。
它们是 MIT 帧字段，单位为 N·m/rad、N·m·s/rad，与上层位置→速度 PID 的增益不同；不写 CSP 内部 PID、零位或 flash。

准备/只读连接不发 MIT。明确启动后读取并缓存新鲜当前位置，逐轴 enable 后立即发送该轴首帧，中间不插入其它轴操作；给失能电机发送的帧不算成功预载。
SDK 的 enable 与首帧不是硬件原子操作，真实启动的短暂行为尚未验证。无重力前馈时，承重姿态会有 PD 静差，初值不等于实机已调好。
每次发送额外检查由反馈估计的 PD 力矩不超过既有包络；该估计不是力矩传感器或物理力矩保证。设备原限速不提高，原电流/力矩运行参数按会话快照恢复。

通信超时后清除输入和轨迹，冻结末目标并锁定恢复，不调用自动失能或自动回零。MIT 保留末帧的物理效果仍待现场验收，CAN/驱动失电时软件无法保证承重。
MIT 目标没有 CSP loc_ref 读回确认：末帧结果不确定时一直锁定；不能拿 0x7016 冒充 MIT 目标确认。新鲜反馈只允许操作者重新接管，不恢复旧轨迹。
由于 MIT 模式 0 无法证明失能，首次 enable 前原子记录完整参数快照与写入意图；异常退出再启动必须核对停止/恢复，即使六轴模式都为 0。恢复来源沿用既有会话记录格式。

驱动配置仅在完整范围、只读、未准备、无控制者且无恢复故障时应用，应用后预览、程序检查与算法试算作废。
MIT 参数保存在 `outputs/twin-console/hardware/drive-settings.json`；驱动选择重启归 CSP，防止连接时自动改变真实后端。
