## 当前电脑启动

在本工程根目录运行：

```bash
./rebotarm start all
```

打开 <http://127.0.0.1:3002/>。此入口启动或复用 Fake、MuJoCo、rosbridge 和网页，不自动连接实机或使能。

实机由网页“连接实机反馈”启动 `scripts/start_rs_twin.sh`，默认只读。先核实 CAN 与新鲜反馈，再明确准备、接管或点击“使能并执行程序”。导入、载入、打开页面本身不执行程序，仿真可选。

`./rebotarm start rs` 属于旧驱动生命周期入口，与当前受管网页驱动不同；不要同时启动两条实机控制链路。旧版125Hz MIT、重力补偿等描述不代表当前CSP工作台的实际频率或已验收能力。

## 功能与默认配置

- 坐标、键盘、标准手柄、TCP 拖拽、J7 开合和动作程序共用执行链路。
- 完整六轴默认 Ruckig 参考与 CSP 驱动；可在只读配置中选择五次曲线或 MIT 位置 PD。
- P、PD、PID、增益调度 PID、LADRC、线性 MPC 各有独立参数；显式启动反馈控制后才接管固定目标。
- 完整模式命令期限500ms，小幅模式300ms；电机字段反馈、网页、心跳和手动输入各有独立期限。
- 完整已出力时通信失联进入HOLDING，冻结已有目标、不自动续跑；明确失能、Esc、重置或服务退出仍可能撤力。先可靠支撑再撤力。
- 程序库、示教、相机、视觉与大模型接口已接入；外部模型、密钥与标定由使用方配置。

## 安装与迁移

推荐 Ubuntu 24.04 / ROS 2 Jazzy / Python 3.12 / Node.js 22及以上（需全局WebSocket/fetch），CAN 为1Mbps。Ubuntu 22.04 / Humble 是需重新回归的兼容路径。

按[交付文档第3节](docs/项目交付文档_2026-10-17.md)安装。先运行 `bash scripts/setup_csp_sdk.sh` 准备清单锁定的6415d431 CSP SDK，再运行基础安装及 `./rebotarm doctor`；用 `bash scripts/setup_csp_sdk.sh --check` 单独只读核对依赖。doctor和构建入口已识别该已登记checkout，不要删除SDK的`.git`。网页3002及ROSBridge9090的新启动默认只监听127.0.0.1，全部HTTP API统一限制本机来源；这不等于ROS/DDS完整鉴权，详见本轮改进记录。

2026-10-22 仓库快照已汇入此前未提交的新功能。程序、恢复记录及算法档案的迁移范围以根目录 HANDOFF.md 与 handoff/ARTIFACTS.json 为准；连接密钥需要在新设备重新配置。
