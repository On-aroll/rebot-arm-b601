# B601 RS 傻瓜式启动与操作

## 1．双击桌面图标

双击 **ReBot Arm B601-RS 项目启动台**。它只启动网页并打开启动页面；已经打开网页时，访问 [项目启动台](http://127.0.0.1:3002/startup.html)。

## 2．从上往下点击

启动台默认连接 **真实机械臂**，按编号操作：检查 ROS 2 环境 → 启动 ROS 联动接口 → 启用 CAN → 启动只读反馈。已是绿色的步骤可以直接跳过，或点击「检查 / 复用」。

实机先接好 USB-CAN、打开本体电源。启用 CAN 如弹出系统认证窗口，在本机输入管理员密码即可。每步都有实际状态和可展开的启动日志；出错先看该步提示。

## 3．点击「进入操作工作台」

全部必需步骤就绪后，点击进入，页面会连接所选对象的反馈。**左侧工具栏切换功能，右侧填写参数、输入坐标、查看指导和模型 / 相机画面。**

- **手动移动**：实机勾选现场确认，再点「使能并进入手动控制」；从左侧选择坐标、键盘、手柄或 TCP。键盘按住空格，手柄按住 RB 才移动。
- **TCP拖动选点**：按住末端绿点选择目标，松手后自动平滑到点、接近时减速并停稳；自动调速，无需调整平移滑条。要中止到点可点「暂停并保持」。
- **运行程序**：左侧「动作程序」→ 导入 JSON 或载入「国庆快乐」→「使能并执行程序」。导入、打开页面和切换功能均不执行动作。
- **其他功能**：示教、相机、速度、调参、视觉规划、大模型、服务状态和维护都在左侧。MCP 与文本代理是启动台内的可选仿真服务；模型服务及相机需要相应配置。

## 暂停与结束

临时停下用顶部 **暂停并保持**。

使用结束，按下面操作：

1. 让机械臂有支撑，再点 **失能撤力 / Esc**，等待只读状态。撤力后机械臂可能下落，必须先支撑。
2. 点击工作台或启动台右上角 **结束项目**。
3. 勾选确认，点击 **确认结束项目**，等待退出进度完成。
4. 看到 **项目已结束** 页面后，直接关闭网页。下次使用仍双击桌面启动台。

退出会依次停止本工程的实机只读驱动、可选代理、仿真和 ROS 联动接口，最后关闭网页服务及三维画面。实机仍在运动、保持或状态无法确认时，退出会被阻止，按提示处理即可。

**直接关闭标签页不会结束后台。** 悬空保持时不要关闭驱动服务或切断电源。此功能不关电脑、不关闭 CAN 接口，也不结束其他工程的服务。
