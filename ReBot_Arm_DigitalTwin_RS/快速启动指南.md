# B601 RS 傻瓜式启动与操作

## 1．双击桌面图标

双击 **ReBot Arm B601-RS 项目启动台**。它会打开网页并自动检查 ROS、联动接口和 CAN，启动唯一实机只读反馈及 Gemini 相机采集；不会使能电机。已经打开网页时，访问 [项目启动台](http://127.0.0.1:3002/startup.html)。

## 2．等待一键检查完成

启动台固定连接 **真实机械臂**，自动按顺序检查：ROS 环境 → 联动接口 → CAN → 只读反馈 → 相机。也可点击「一键检查并启动实机与相机」，或单独重试某一步；已就绪的服务会复用，不重复创建。

实机先接好 USB-CAN、打开本体电源。启用 CAN 如弹出系统认证窗口，在本机输入管理员密码即可。每步都有实际状态和可展开的启动日志；出错先看该步提示。

## 3．点击「进入操作工作台」

全部必需步骤就绪后，点击进入，页面会连接所选对象的反馈。**左侧工具栏切换功能，右侧填写参数、输入坐标、查看指导和模型 / 相机画面。**

如果显示“需恢复”，进入左侧“重置与维护”。可靠支撑后点击“已支撑，恢复连接与状态”，本次点击就是现场确认；核查通过才解除恢复锁。相机画面异常也可从这里恢复采集，或在“相机画面”点击“连接画面”。

- **手动移动**：实机勾选现场确认，再点「使能并进入手动控制」；从左侧选择坐标、键盘、手柄或 TCP。键盘按住空格，手柄按住 RB 才移动。
- **TCP拖动选点**：按住末端绿点选择目标，松手后自动平滑到点、接近时减速并停稳；自动调速，无需调整平移滑条。要中止到点可点「暂停并保持」。
- **运行程序**：左侧「动作程序」→ 导入 JSON 或载入「国庆快乐」→「使能并执行程序」。导入、打开页面和切换功能均不执行动作。
- **其他功能**：示教、相机、速度、调参、视觉规划、大模型、服务状态和维护都在左侧。MCP 与文本代理是启动台内的可选仿真服务；模型服务及相机需要相应配置。

## 暂停与结束

临时停下用顶部 **暂停并保持**。

使用结束，按下面操作：

1. 给机械臂提供可靠支撑，确保撤力后仍能稳定停放。
2. 点击工作台或启动台右上角 **结束项目**，勾选已支撑并允许失能撤力，再点击 **确认结束项目**。
3. 等待项目核对失能回包并关闭后台。看到 **项目已结束** 后即可关闭网页，下次使用仍双击桌面启动台。

退出时先撤销实机控制并请求失能。收到失能回包后，关闭本工程的驱动、相机、仿真、联动接口及网页服务。待恢复的参数和故障记录保留到下次维护，电脑仍可识别 USB-CAN。

如果 CAN 掉线且项目无法核对失能，可靠支撑机械臂并实际断开本体电机电源后，可以勾选断电确认并结束故障后台。**关闭标签页只会关闭网页。**

命令和工程位置见 [详细启动与排障](docs/详细启动与排障_2026-10-17.md)。主工程是当前仓库的 `ReBot_Arm_DigitalTwin_RS/`。移动工程后，在主工程目录运行 `bash scripts/install_desktop_launcher.sh`，即可按新位置重建桌面和应用菜单入口。
